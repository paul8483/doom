# Волна 16, сет 1: AQF-хвост флэтов — ржавый металл — 12 текстур (GPT 5.6 SOL)

Полы/потолки 64×64, редрав 4× = 256×256, тайлинг по обеим осям.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, ровно 256×256.
3. Сказать ассистенту — валидатор (обе оси), ВЧ-проверка на копийность,
   тон, квант, панели. Установка — ОДИН раз в конце всей волны.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ДВЕНАДЦАТЬ текстур ПОЛОВ/ПОТОЛКОВ из классического DOOM
(Freedoom, aquatex) в повышенной детализации. Это ржавый клёпаный металл
затопленной техно-базы: плиты, доски, решётчатые панели, плетёнка.
Ядро семейства уже принято — новые обязаны смотреться в одном ряду с ним.

**Эталоны aquatex-флэтов** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQF024\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\AQF028\redraw.png`

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый элемент входа
(плита, шов, прорезь, заклёпка, планка) остаётся ровно на своём месте и
ровно своего размера в долях холста; число плит, прорезей и заклёпок не
менять. Перед сохранением сверь силуэты: наложение результата на вход в
полупрозрачности не должно показывать сдвигов.

**ВТОРОЕ — не копия:** каждый входной тексель — квадрат 4×4; ни один
такой квадрат не должен выжить как есть, внутри — новая деталь (зерно
ржавчины, потёртости, фаски).

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 12 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **AQF001** → четыре крупные ржавые квадратные плиты 2×2 с фасками и
   крестовым швом; тёмные пятна окалины по плитам.
2. **AQF002** → плотная диагональная плетёнка из мелких ржавых
   скоб-звеньев (металлическая «корзинка»); шаг плетения ровно по входу.
3. **AQF003** → четыре вертикальные колонны-лесенки: в каждой —
   вертикальный ряд квадратных тёмных прорезей на ржавой полосе; между
   колоннами гладкие тёмные зазоры.
4. **AQF004** → та же конструкция горизонтально: четыре горизонтальных
   пояса с рядами квадратных тёмных прорезей.
5. **AQF007** → ржаво-бурый металл почти без структуры: вертикальные
   потёки, сине-серые пятна; фактуру детализировать, пятна на местах.
6. **AQF009** → четыре широкие вертикальные ржавые панели с тонкими
   тёмными швами между ними.
7. **AQF021** → две горизонтальные секции решётки: ряд высоких
   вертикальных тёмных прорезей в ржавой раме со светлой кромкой сверху;
   секция повторяется дважды по вертикали.
8. **AQF029** → чередование вертикальных полос: полосы с вертикальным
   рядом круглых заклёпок-бобышек и тёмные рёбра между ними.
9. **AQF030** → горизонтальная версия той же системы: пояса с рядами
   круглых заклёпок, между ними тёмные рёбра.
10. **AQF031** → частые вертикальные ржаво-бурые доски-планки с тёмными
    швами; число планок ровно по входу.
11. **AQF033** → широкие вертикальные тёмные доски с неровными краями и
    швами; число досок ровно по входу.
12. **AQF034** → четыре широкие горизонтальные доски с тёмными швами.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех** (это полы —
   узор продолжается во все стороны).
3. **Серии остаются сериями**: AQF003/004 — одна решётчатая система в
   двух ориентациях; AQF029/030 — одна клёпаная система; AQF031/033/034 —
   одно семейство досок.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и направленных теней; ничего не светится.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; больше деталей —
   зерно ржавчины, царапины, окалина, фаски. НЕ фотореализм. Никаких
   надписей.
