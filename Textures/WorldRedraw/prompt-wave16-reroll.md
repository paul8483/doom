# Волна 16, ре-ролл композиции: AQF003 + AQF055 — 2 текстуры (GPT 5.6 SOL)

Полы/потолки 64×64, редрав 4× = 256×256, тайлинг по обеим осям.
Причины ре-ролла: AQF003 — прорези нарисованы квадратными окнами, у
натива они АРОЧНЫЕ (подкова); AQF055 — у нижней кромки дорисована
светлая линия, которой в нативе нет (в тайле даёт двойную полосу).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, ровно 256×256.
3. ПЕРЕД приёмкой ассистент удаляет старые `redraw-raw.png` этих двух
   текстур (правило ре-роллов — иначе тон-матч подхватит старое сырьё).
4. Дальше стандартно: валидатор (обе оси), тон, квант, панели.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ДВЕ текстуры ПОЛОВ/ПОТОЛКОВ из классического DOOM (Freedoom,
aquatex) в повышенной детализации. Это ре-ролл: первая генерация ушла от
композиции оригинала — теперь позиции элементов пришпилены процентами,
следуй им точно.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQF004\redraw.png` (принятая решётчатая панель того же семейства)
- `C:\Development\doom\Textures\WorldRedraw\AQF051\redraw.png` (принятая серая плита того же семейства)

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один по входу и по процентным
пинам ниже.** Перед сохранением сверь силуэты: наложение результата на
вход в полупрозрачности не должно показывать сдвигов.

**ВТОРОЕ — не копия:** каждый входной тексель — квадрат 4×4; ни один
такой квадрат не должен выжить как есть.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 2 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **AQF003** → четыре вертикальные ржавые колонны-лесенки с рядами
   тёмных прорезей. **ГЛАВНЫЙ ПИН — ФОРМА ПРОРЕЗИ: у каждой прорези
   АРОЧНЫЙ верх (подкова/туннель) со светлым бликом по дуге арки, низ
   прямой; НЕ рисуй квадратные окна с рамками.** Смотри форму во входе —
   светлая дуга над каждым тёмным проёмом. Сетка: колонны шириной 16
   текселей входа (тёмный зазор на 0%, светлая кромка на ~3%, тело
   колонны), в каждой колонне ~9 прорезей с шагом ~11% высоты — число и
   позиции ровно по входу.
2. **AQF055** → серый бетон с горизонтальными светлыми
   полосами-ступенями. **ГЛАВНЫЙ ПИН: светлых полос РОВНО ДВЕ — на
   0–10% и на 50–58% высоты (это один узор, повторённый дважды по
   вертикали); НИЖНЯЯ КРОМКА (85–100%) — тёмный шершавый бетон БЕЗ
   светлой линии.** Под каждой полосой яркая кромка, дальше вниз бетон
   постепенно темнеет до следующей полосы. Тайл по вертикали замыкается
   сам: тёмный низ переходит в светлую полосу следующего тайла.

Правила (те же, что у эталонов):
1. Композиция один-в-один + процентные пины (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у обеих.**
3. **Серии остаются сериями**: AQF003 — пара к принятой AQF004 (одна
   решётчатая система, та же ржавчина); AQF055 — семейство принятых
   серых плит AQF051/AQF052.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток; ничего не светится.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; детали — зерно
   ржавчины/бетона, потёртости. НЕ фотореализм. Никаких надписей.
