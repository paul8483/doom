# Ре-ролл композиции: пара SW1COMP / SW2COMP (GPT 5.6 SOL)

Редрав волны 12 провалил «композицию один-в-один»: стальная плита
переключателя нарисована у́же и сдвинута ВНИЗ ~10 текселей (экран уехал
с y 62.5–68.8% на ~70–75%, индикатор с y ~70% на ~80%, низ плиты с
клавиатурой вылез за кадр окна ниши). На E1M2 (линия 1854) ниша высотой 32
юнита показывает тексельные строки 72..104 — там натив обрамляет плиту
целиком, а редрав показывает только её верхушку с обрезанными кнопками.
Ре-ролл с процентными пинами (образец — composition-reroll волны 14).

## Как пользоваться (инструкция для нас, не для GPT)

1. Перед приёмкой удалить старые `redraw-raw.png` обеих текстур.
2. Отправить текст промпта ниже одной сессией.
3. Ожидаемый выход: `redraw.png` в папке каждой текстуры.
4. Приёмка: валидатор → сверка позиций элементов (замеры ниже) →
   тон-матч → `enforce_switch_pair.py` → квант → установка.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ПАРУ текстур переключателя из классического DOOM (Freedoom) в
повышенной детализации. Предыдущая попытка сдвинула панель вниз и сжала
её — теперь каждый элемент пинится процентами холста. СНАЧАЛА измерь
вход, ПОТОМ рисуй; перед сохранением наложи результат на вход в
полупрозрачности и убедись, что сдвигов НЕТ.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\COMPUTE1\redraw.png` (техника COMP)
- `C:\Development\doom\Textures\WorldRedraw\COMPTALL\redraw.png` (стойка кабелей)

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа (256×512). Ничего, кроме этих 2 `redraw.png`, не записывай.

**SW1COMP / SW2COMP** → 256×512 каждая. Сверху тёмная стойка кабелей и
плат (верхняя половина холста, композиция как во входе), снизу стальная
контрольная панель. КРИТИЧНЫЕ ПИНЫ (проценты холста, мерены по входу):

1. Стальная плита панели: ширина РОВНО 25%–75% холста (тексели 16–47 из
   64), высота РОВНО 56%–80.5% (тексели 72–102 из 128). Плита
   ЦЕНТРИРОВАНА по горизонтали. НЕ сдвигать вниз, НЕ сужать, НЕ
   добавлять тёмную стену по бокам плиты внутри этой зоны.
2. Зелёный экран: x 36%–50%, y 62.5%–68.8% (левая верхняя четверть
   плиты). Светится локально, без ореола на полстены.
3. Решётка тёмных кнопок/перфорации: правая половина плиты, x ~52%–73%,
   y ~57%–74% — рисуй сетку тёмных клавиш как во входе.
4. Оранжевая кнопка-индикатор: маленькая, у центра, x ~50%–53%,
   y ~70.3%–71.9%. ОДНА, не увеличивать в красный брус.
5. Малая клавиатура: под экраном, в нижней трети плиты (y ~72%–80%),
   как во входе.
6. Ниже плиты (y 80.5%–100%) — тёмный металл фона, как во входе, БЕЗ
   продолжения панели.

**ГЛАВНОЕ ПРАВИЛО ПАРЫ.** СНАЧАЛА сравни входы SW1COMP и SW2COMP: у них
меняется ТОЛЬКО содержимое зелёного экрана (зона x 36%–50%,
y 61.7%–68.8%). Рисуй SW1COMP полностью, сохрани, скопируй и измени
ТОЛЬКО экран для SW2COMP — диф вне зоны экрана обязан быть нулевым.
Оранжевая кнопка НЕ меняется между состояниями.

Правила: бесшовный тайлинг по горизонтали И вертикали у обоих членов
пары; композиция один-в-один с входом — каждый входной тексель — квадрат
4×4, внутри новая честная деталь (зерно металла, свечение пикселей
экрана, потёртые клавиши); без запечённого света; стиль — мрачный
ретро-индастриал, гамма оригинала, НЕ фотореализм, никаких надписей
кроме нечитаемых пиктограмм экрана как во входе.

## Приёмка после генерации (наша часть, в GPT не отправлять)

```
python Tools/validate_tile_redraw.py SW1COMP SW2COMP
```

Затем проверка пинов (замеры натива, тексели 64×128 / проценты):
- плита x 16–47 (25–75%), y 72–102 (56.2–80.5%)
- зелёный экран x 23–31 (36–50%), y 80–87 (62.5–68.8%)
- оранжевая кнопка x 32–33, y 90–91
- диф пары: только зона экрана x 23–31, y 79–87 (81 тексель в нативе)

Дальше: тон-матч (`tone_match_redraw.py`), `enforce_switch_pair.py`
(SW2 вне зоны экрана = пиксели SW1), квант, установка. Гейт в игре —
сейв слота 0 (E1M2, ниша line 1854, окно текселей 72..104).
