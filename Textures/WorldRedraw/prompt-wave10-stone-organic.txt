# Волна 10, сет 4: камень, органика, лампа (флэты) — 5 текстур (GPT 5.6 SOL)

Флэты полов/потолков. Все нативы 64×64, редрав 4× = 256×256.
TLITE6_5 — потолочная лампа в ламповом мерцании: сетка из 4 плафонов
пиннится пиксель-в-пиксель (как AQLITE18 в волне 8, IoU-проверка).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, ровно 256×256.
3. Сказать ассистенту — валидатор (обе оси!), IoU плафонов, хью-проверка
   зелени/синевы, тон, квант, установка.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ПЯТЬ текстур ПОЛОВ и ПОТОЛКОВ из классического DOOM (Freedoom)
в повышенной детализации. Камень, щебень, лозы, ковровое покрытие и
потолочная лампа. Стены уровней уже перерисованы — не выбивайся из
мрачного ретро-индастриала.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `D:\Development\doom\Textures\WorldRedraw\GSTONE1\redraw.png` (камень)
- `D:\Development\doom\Textures\WorldRedraw\MC17\redraw.png` (мох/зелень)
- `D:\Development\doom\Textures\WorldRedraw\AQLITE18\redraw.png` (световая панель — эталон дисциплины плафонов)

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый валун, лоза и плафон
остаётся ровно на своём месте и ровно своего размера в долях холста.
Перед сохранением сверь наложением в полупрозрачности.

**ВТОРОЕ ПРАВИЛО — не копия.** Вход растянут из 64×64, каждый исходный
тексель — квадрат 4×4. Ни один такой квадрат не должен выжить: внутри
каждого — новая мелкая деталь.

**ТРЕТЬЕ ПРАВИЛО — цвет-идентичность.** Зелёное остаётся зелёным
(FLOOR7_2 — лозы), синее остаётся синим (FLAT14 — ковёр), красные плафоны
TLITE6_5 остаются красными и ЯРКИМИ. Не буреть, не глушить.

Вход каждой текстуры: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 5 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **CEIL5_1** → 256×256. Тёмный серо-чёрный щебень/битый камень, плотная
   хаотичная масса. Самая используемая текстура волны — аккуратно: рисунок
   осколков ровно с входа, тёмный тон сохранить.
2. **MFLR8_1** → 256×256. Тёмная каменная кладка крупными неровными
   блоками со швами. Раскладка блоков — с входа.
3. **FLOOR7_2** → 256×256. Зелёные лозы/плющ плотным ковром по тёмной
   земле. Маршруты лоз — с входа; зелень НЕ буреет.
4. **FLAT14** → 256×256. Тёмно-синее ковровое покрытие с мелким ворсом.
   Синий — идентичность текстуры; добавить ворс/плетение, не менять цвет.
5. **TLITE6_5** → 256×256. Потолочная плита тёмного камня с ЧЕТЫРЬМЯ
   круглыми красными плафонами по одному в каждой четверти. КАЖДЫЙ плафон:
   центр, диаметр и круглая форма — пиксель-в-пиксель с входом (по ним
   привязано мерцание света). Светлая окантовка плафонов сохраняется.
   Детализировать можно камень плиты и фактуру стекла ВНУТРИ плафона,
   не трогая его границу.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех пяти.**
3. **Без запечённого света**: равномерное нейтральное освещение. Свечение
   плафонов TLITE6_5 — цвет стекла, не ореол по камню: гало вокруг
   плафонов с входа не расширять.
4. **Стиль**: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей.
