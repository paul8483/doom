# Волна 15, сет 3: FIREBLU1–2 — адское сине-красное пламя (GPT 5.6 SOL)

Особый случай трека: два кадра хаотического пламени, меняющегося ЦЕЛИКОМ
(нативный межкадровый диф 16.3 — крупнейший среди анимаций). Пин вне
зоны неприменим — зона и есть вся текстура; нативная анимация — жёсткая
смена двух состояний турбулентности, и перерисовка наследует этот
характер. Рисуются ПАРОЙ одной сессией ради единого стиля/гаммы.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папках FIREBLU1 и FIREBLU2.
3. Сказать ассистенту — валидатор, тон, панели (включая мигающую пару
   рядом). Имплементация — один раз в конце волны. Если мигание в игре
   провалит гейт — фолбэк Super-xBR по паре (2 сайддефа E1M8).

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ДВЕ текстуры стен из классического DOOM (Freedoom) в
повышенной детализации. Это FIREBLU — стена сплошного адского пламени,
где синие и красные языки хаотически прорастают друг сквозь друга.
Кадры — два состояния одной и той же турбулентности: один стиль, одна
гамма, одна крупность языков; различается только рисунок хаоса.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа (512×512). Ничего, кроме этих 2 `redraw.png`,
не записывай.

1. **FIREBLU1** → перерисовка первого состояния: крупные пятна синего
   и красного пламени ровно там, где они во входе (композиция
   один-в-один), но каждый язык прорисован — рваные кромки, искры,
   тёмные прогалы между языками.
2. **FIREBLU2** → второе состояние: своя композиция по своему входу,
   тот же стиль и та же плотность детали, что у кадра 1.

Правила (общие для трека):
1. **Композиция один-в-один по своему входу** (баланс синего/красного
   и расположение крупных масс сохранить; сверь по входу).
2. Анти-копия: больше высокочастотной детали, чем вход; ни один
   fat-pixel квадрат 4×4 не должен выжить.
3. **Бесшовный тайлинг по обеим осям** (пламя заливает стены любых
   размеров).
4. **Стиль**: мрачный ретро-индастриал DOOM, гамма оригинала —
   глубокий синий + алый, без фиолетовой каши на смешении;
   НЕ фотореализм. Никаких надписей.

## Приёмка после генерации (наша часть, в GPT не отправлять)

```
python Tools/validate_tile_redraw.py FIREBLU1 FIREBLU2
python Tools/tone_match_redraw.py FIREBLU1 FIREBLU2
python Tools/quantize_to_playpal.py FIREBLU1 FIREBLU2
```

Плюс проверка пары: гистограммная близость кадров (яркость/доля синего
против нативной пары) и панель-мигалка 1↔2 рядом с нативной.
