Полы/потолки 64×64, редрав 4× = 256×256, тайлинг по обеим осям.
AQF022 — правило зелени: зелёное остаётся зелёным (доля зелёных
текселей проверяется хью-маской, урок волны 9).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, ровно 256×256.
3. Сказать ассистенту — валидатор (обе оси), хью-маска зелени AQF022,

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ТРИ текстуры ПОЛОВ/ПОТОЛКОВ из классического DOOM (Freedoom,
aquatex) в повышенной детализации: битая керамика, предупредительная
разметка и мох. Семейство aquatex уже принято — новые обязаны смотреться
в одном ряду с ним.

**Эталоны aquatex-флэтов** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQF024\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\AQF054\redraw.png`

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый элемент входа
(панель, пролом, полоса разметки, пятно мха) остаётся ровно на своём
месте и ровно своего размера в долях холста. Перед сохранением сверь
силуэты: наложение результата на вход в полупрозрачности не должно
показывать сдвигов.

**ВТОРОЕ — не копия:** каждый входной тексель — квадрат 4×4; ни один
такой квадрат не должен выжить как есть.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 3 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **AQF013** → панели оранжево-терракотовой керамики в тёмной
   металлической раме, три пояса: верхний и нижний ряды мелких панелей,
   средний — крупные. В панелях РВАНЫЕ тёмные проломы и трещины — рисунок
   каждого пролома ровно по входу (это боевые повреждения, не орнамент);
   керамика с мелкой фактурой чешуек.
2. **AQF018** → жёлто-чёрная диагональная предупредительная разметка,
   нанесённая поверх вертикальных клёпаных стальных планок; видны швы
   планок и заклёпки сквозь краску; угол и толщина полос ровно по входу;
   жёлтый остаётся жёлтым; краска с потёртостями до металла.
3. **AQF022** → зелёный мох/поросль пятнами поверх тёмно-бурой земли;
   ЗЕЛЁНОЕ ОСТАЁТСЯ ЗЕЛЁНЫМ, доля и расположение зелёных пятен ровно по
   входу; детали — листики, прожилки мха, комочки земли.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех.**
3. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и направленных теней; ничего не светится.
4. **Стиль**: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей.
