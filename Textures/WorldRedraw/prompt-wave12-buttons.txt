# Волна 12, сет 2: переключатели-КНОПКИ и череп — 3 пары / 6 файлов (GPT 5.6 SOL)

Пара SW1 (выключен) / SW2 (включён) рисуется как ОДНА композиция:
меняется только сам актуатор (кнопка / глаза черепа).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: по два `redraw.png` на пару.
3. Сказать ассистенту — валидатор, диф пары, тон, квант, установка.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ТРИ ПАРЫ текстур переключателей из классического DOOM (Freedoom)
в повышенной детализации: две настенные кнопки и одна ниша с черепом.
SW1 — выключен, SW2 — включён.

**ГЛАВНОЕ ПРАВИЛО ПАРЫ.** Внутри пары всё, кроме актуатора, обязано быть
ИДЕНТИЧНЫМ попиксельно: рисуй SW1 полностью, сохрани, затем скопируй и
измени ТОЛЬКО актуатор для SW2.

**ВТОРОЕ ПРАВИЛО — композиция один-в-один с входом.** Позиции ниш, швы,
ряды заклёпок — ровно как во входе. Не копия: каждый входной тексель —
квадрат 4×4, внутри новая деталь.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ):
- `D:\Development\doom\Textures\WorldRedraw\SLADWALL\redraw.png` (зелёный шлак SLAD)
- `D:\Development\doom\Textures\WorldRedraw\STONE2\redraw.png` (тёмный камень STON2)
- `D:\Development\doom\Textures\WorldRedraw\COMPBLUE\redraw.png` (синяя техностена BLUE)

Вход: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Выход: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`, ровно
в размере входа. Ничего, кроме этих 6 файлов, не записывай.

Пары (все 256×512):

1. **SW1SLAD / SW2SLAD** → 256×512. Зелёная шлаковая стена рядами с
   заклёпками, в центре стальная рамка с КРАСНОЙ кнопкой: SW1 — кнопка
   выступает, тёмно-красная; SW2 — кнопка утоплена и ГОРИТ ярко-красным.
2. **SW1STON2 / SW2STON2** → 256×512. Тёмная каменная кладка, в центре
   стальная рамка с красной кнопкой: SW1 — выступает, тёмная; SW2 —
   утоплена, горит.
3. **SW1BLUE / SW2BLUE** → 256×512. Синяя техно-стена с плетёным
   рельефом, в нижней части каменная ниша-грот с ЧЕРЕПОМ в зелени:
   SW1 — глазницы черепа ТЁМНЫЕ; SW2 — в глазницах горят КРАСНЫЕ огни
   (свет только в глазницах, без ореола на всю нишу). Форма черепа,
   ниши и лозы — одинаковые в паре, ровно по входу.

Правила:
1. Правило пары — диф SW1↔SW2 вне зоны актуатора нулевой.
2. Бесшовный тайлинг по горизонтали И вертикали у обоих членов пары.
3. Без запечённого света (кроме честного свечения кнопки/глаз в SW2 —
   это игровой сигнал, локализованный в актуаторе).
4. Стиль: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей.
