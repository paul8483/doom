# Волна 15, сет 1: водопады — 3 текстуры-якоря (GPT 5.6 SOL)

Кадры 2–4 каждой серии НЕ рисуются: они синтезируются детерминированно
вертикальной прокруткой якоря (128 px на кадр при 4×), поэтому весь цикл
анимации по построению состоит из одних и тех же текселей. Отсюда два
специальных правила этого сета (см. ниже «КРИТИЧНО ДЛЯ АНИМАЦИИ»).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой из трёх текстур.
3. Сказать ассистенту — валидатор (шов ПО ОБЕИМ осям), тон, синтез
   кадров 2–4 прокруткой, панели. Имплементация — один раз в конце
   волны, после приёмки всех сетов.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ТРИ текстуры стен из классического DOOM (Freedoom) в
повышенной детализации. Это водопады — вертикально падающие потоки
(шлам, вода, кровь) во всю высоту стены. Из каждой перерисовки будут
детерминированно собраны кадры анимации прокруткой по вертикали.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа (256×512). Ничего, кроме этих 3 `redraw.png`,
не записывай.

Соответствие (имя → что на текстуре):

1. **SFALL1** → тёмно-зелёный шламопад: узкие струи и потёки токсичной
   жижи на почти чёрном фоне; зелёный ОСТАЁТСЯ зелёным той же гаммы.
2. **WFALL1** → синий водопад: плотные вертикальные струи воды, более
   яркие столбы-стержни как во входе; синий остаётся синим.
3. **BFALL1** → кровепад: тёмно-красные вертикальные струи; красный
   остаётся красным, без ухода в оранжевый.

**КРИТИЧНО ДЛЯ АНИМАЦИИ (главные правила сета):**
1. **Бесшовный тайлинг ПО ОБЕИМ ОСЯМ** — и по горизонтали, и по
   вертикали: верхний край обязан продолжать нижний без стыка (кадры
   анимации — вертикальные сдвиги этой картинки).
2. **Статистическая равномерность по высоте**: никакого градиента
   яркости сверху вниз, никаких виньеток, никакой уникальной крупной
   детали, выделяющейся на фоне остального потока (при прокрутке она
   читалась бы как бегущая по кругу метка). Струи могут виться, но
   плотность/яркость потока в любой горизонтальной полосе примерно
   одинакова, как во входе.

Правила (общие для трека):
1. **Композиция один-в-один по входу**: расположение и толщина главных
   струй сохраняются, светлое остаётся светлым, тёмное тёмным.
2. Анти-копия: перерисовка обязана нести БОЛЬШЕ высокочастотной детали,
   чем вход; ни один fat-pixel квадрат 4×4 не должен выжить.
3. **Стиль**: мрачный ретро-индастриал DOOM, гамма оригинала; струи с
   бликами, брызги мелкие; НЕ фотореализм, без «мыла» и размытия по
   направлению потока. Никаких надписей.
