# Волна 17: SKY1 — небо эпизода, 1 текстура (GPT 5.6 SOL)

Натив 256×128 — единственная текстура эпизода без редрава. В порту небо
натянуто ОДНОЙ копией на всю сферу вокруг игрока: ширина = 360° поворота,
высота = от зенита (верхний ряд) до надира (нижний ряд), горизонт ровно
по середине высоты. Это самая крупная магнификация в игре (на 1920 px
при FOV 90° один нативный тексель ≈ 30 px), поэтому контракт этой волны —
**8× = 2048×1024**, а не обычные 4×. Если генератор не может выдать
2048×1024 — выдать 1024×512 (4×), не растягивать.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `Textures/WorldRedraw/SKY1/redraw.png`, ровно 2048×1024
   (или 1024×512 как фолбэк).
3. Сказать ассистенту — валидатор (шов только по горизонтали; по вертикали
   НЕ тайлится — полюса), проверка «не копия» по ВЧ, тон, квант, панель.
   Рантайм: пер-имя масштаб в `WorldRedrawAllowlist`/`WorldRedrawCatalog`
   (SKY1 → 8), небо и так берёт `Enhanced4X`-вариант через `TextureCache`.
   Установка — после приёмки по картинке.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй НЕБО из классического DOOM (Freedoom, E1) в повышенной
детализации. Это сферическая панорама: левый и правый края холста
смыкаются за спиной игрока, верхний ряд пикселей стягивается в точку
зенита, нижний — в точку надира, горизонт проходит ровно по середине
высоты холста. Стены и небо мира уже перерисованы в едином стиле — небо
обязано встать в тот же ряд.

**Эталоны стиля мира** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\GRASS1\redraw.png` (трава/мох)
- `C:\Development\doom\Textures\WorldRedraw\ROCK5\redraw.png` (камень)
- `C:\Development\doom\Textures\WorldRedraw\STONE2\redraw.png` (кладка со мхом)

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый элемент входа
остаётся ровно на своём месте и ровно своего размера в долях холста:
- два холма — левый (вершина ~x 22%, y 54%) и правый, более высокий
  (вершина ~x 60%, y 52%); их силуэты, седловина между ними (~x 40%,
  y 65%) и правый склон, уходящий за край (~x 100%, y 68%) — по входу;
- линия перехода холмов в туман — ~y 78–86%; ниже — сплошной светло-серый
  туман до нижнего края;
- облачные массы: тёмная плотная гряда над холмами (~y 45–55%), светлые
  кучевые массы вверху слева и справа, светлое пятно над правым холмом
  (~x 88%, y 60%) — ровно по входу;
Перед сохранением сверь силуэты холмов и облачных масс наложением
результата на вход в полупрозрачности: сдвигов быть не должно.

**ВТОРОЕ — не копия:** каждый входной тексель — квадрат 8×8 на выходе
(4×4 при фолбэке 1024×512); ни один такой квадрат не должен выжить как
есть. Облака — мягкие объёмные массы с внутренней структурой, холмы —
камень с пятнами мха и рыжей породы (крупные валуны, осыпи, кусты мха),
туман — плавный градиент без полос.

Вход: `C:\Development\doom\Textures\WorldRedraw\upload\SKY1-native-x4.png`
(целочисленное 4× натива 256×128; для выхода 2048×1024 масштаб от входа — 2×).
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\SKY1\redraw.png`
ровно 2048×1024 (если невозможно — ровно 1024×512). Ничего, кроме этого
файла, не записывай.

Правила:
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный стык по горизонтали** (левый край переходит в правый без
   шва — это панорама 360°). По вертикали НЕ тайлится: верхние ~4% высоты
   и нижние ~4% — почти однородный тон (они стягиваются в полюса, любая
   деталь там превратится в звезду-артефакт).
3. **Без запечённого света**: без солнечного диска, лучей, бликов и
   виньеток; освещение ровное, пасмурное. Ничего не светится.
4. **Гамма оригинала**: небо серое пасмурное (не голубое), холмы тёмно-
   зелёные с рыжими проплешинами, туман светло-серый. НЕ фотореализм —
   мрачный ретро-стиль, как у эталонов. Никаких надписей, птиц, построек,
   деревьев, фигур.
