1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, ровно 256×256.
3. Сказать ассистенту — валидатор (обе оси), сверка сетки капсул (IoU,
   смещение центров), тон, квант, панели. Спорные лампы — панелью
   пользователю ДО отбраковки. Установка — ОДИН раз в конце всей волны.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ВОСЕМЬ текстур ПОТОЛКОВ из классического DOOM (Freedoom,
aquatex) в повышенной детализации. Это потолочные световые панели
затопленной техно-базы: сетки светящихся сегментов на тёмном корпусе.
Ламповые панели семейства уже приняты — новые обязаны смотреться в одном
ряду с ними.

**Эталоны** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQLITE18\redraw.png` (принятая световая панель — эталон дисциплины сегментов)
- `C:\Development\doom\Textures\WorldRedraw\FLAT2\redraw.png` (принятая потолочная лампа-флэт)

**ГЛАВНОЕ ПРАВИЛО — сетка сегментов ровно один-в-один по входу.**
Каждая капсула/панель/полоса в своей ячейке; границы ячеек не смещать и
не менять размер (по этой сетке работает покадровое мерцание ламп);
светлое остаётся светлым и своего цвета, корпус тёмным, контраст
светлое/тёмное сохранить. Детализировать можно фактуру корпуса и стекло
ВНУТРИ сегмента, не трогая его границу. Перед сохранением сверь силуэты:
наложение результата на вход в полупрозрачности не должно показывать
сдвигов.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 8 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **AQF010** → четыре колонки БЕЛЫХ скруглённых панелей в три ряда:
   верхний и нижний ряды — короткие панели, средний — высокие; тёмная
   рама между ними.
2. **AQF012** → сетка БЕЛЫХ скруглённых сегментов в четыре колонки;
   верхний ряд выше, ниже — ряды коротких; ряды как во входе.
3. **AQF014** → два ряда по четыре высокие БЕЛЫЕ вертикальные капсулы.
4. **AQF044** → сетка 4×4 круглых ЖЁЛТЫХ ламп на тёмной ржавой раме;
   жёлтый остаётся жёлтым.
5. **AQF058** → две колонки, каждая — вертикальная стопка широких
   коротких БЕЛЫХ сегментов с тонкими тёмными перегородками; число
   сегментов в каждой колонке ровно по входу.
6. **AQF059** → две горизонтальные секции узких вертикальных БЕЛЫХ
   капсул: верхняя секция — капсулы выше, нижняя — короче; число капсул
   в каждой секции ровно по входу.
7. **AQF060** → широкие БЕЛЫЕ горизонтальные световые полосы во всю
   ширину с тёмными зазорами; число полос ровно по входу.
8. **AQF065** → тонкие БЕЛЫЕ горизонтальные световые полосы во всю
   ширину; число полос ровно по входу.

Правила (те же, что у эталонов):
1. Сетка сегментов один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех.**
3. **Серии остаются сериями**: все восемь — одна система светопанелей с
   принятыми AQLITE (тот же тёмный корпус, та же фактура).
4. Светятся ТОЛЬКО сегменты; корпус без запечённого света, без виньеток
   и ореолов вокруг ламп; гало с входа не расширять.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; детали — фаски
   ячеек, лёгкая грязь корпуса; стекло сегментов чистое. НЕ фотореализм.
   Никаких надписей.
