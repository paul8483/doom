## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ПЯТНАДЦАТЬ текстур стен из классического DOOM (Freedoom) в
повышенной детализации. Это металл, техника и заросшие мхом поля одной
военной базы. Единый стиль и освещение на весь набор.

**Эталон уровня детализации** — принятые перерисовки того же эпизода,
повторяй их манеру (плотность деталей, никакого фотореализма):
- `D:\Development\doom\Textures\WorldRedraw\SHAWN2\redraw.png` (серебристый
  металл — SHAWN1/SHAWN02/SHAWN3 из списка ниже это его родня)
- `D:\Development\doom\Textures\WorldRedraw\TEKWALL1\redraw.png` (техно-стена
  — TEKWALL3/TEKWALL5 из списка это её родня)
- `D:\Development\doom\Textures\WorldRedraw\MC17\redraw.png` (мох — MC3/MC5/
  MC19 из списка это его родня)
- `D:\Development\doom\Textures\WorldRedraw\STEP4\redraw.png` (кромка
  ступени — STEP1 из списка это её родня)

Эти файлы ТОЛЬКО ЧИТАТЬ — не перерисовывать и не перезаписывать.

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один**: каждая заклёпка, труба,
экран и логотип остаётся ровно на своём месте и ровно своего размера в
долях холста.

Вход каждой текстуры: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 15 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **BRONZE1** → 256×512. Бронзовые клёпаные плиты, две высокие панели.
2. **BRONZE3** → 256×512. ТА ЖЕ бронза с горизонтальными стыками. Серия с
   BRONZE1.
3. **BASE2** → 512×512. Тёмно-серый шероховатый металл с тонкой верхней
   планкой-отбортовкой.
4. **BASE** → 512×512. Тот же тёмный шероховатый металл сплошным полем.
5. **SHAWN1** → 512×512. Серебристая шлифованная сталь с крупным тёмным
   логотипом «AGM» и эмблемой-петлёй по центру. Надпись «AGM» — родная
   надпись оригинала, воспроизвести читаемой; металл — как у эталона SHAWN2.
6. **SHAWN02** → 512×512. Та же серебристая сталь: четыре широкие
   горизонтальные шлифованные ламели.
7. **SHAWN3** → 256×288. Малая серебристая панель с двумя табличками «AGM»
   (родная надпись, читаемо).
8. **MC3** → 512×512. Тёмное зелёно-бурое моховое поле (родня эталона
   MC17).
9. **MC5** → 512×512. Тёмно-зелёный мох, чуть плотнее.
10. **MC19** → 512×512. Буро-зелёный мох.
11. **TEKWALL3** → 512×448. Тёмная техно-стена с медными элементами
    (родня эталона TEKWALL1).
12. **TEKWALL5** → 512×512. Зелёно-тёмная техно-стена колоннами блоков.
13. **PIPE2** → 1024×512. Стена вертикальных медно-ржавых труб с муфтами
    и одним поперечным коленом.
14. **PLANET1** → 1024×512. Шесть космо-экранов в серебристой раме: экран
    с «AGM» и красным текстом-глифами, красная поверхность планеты,
    спектральные полосы, синее звёздное поле, галактика, купол в
    координатной сетке. Космические изображения остаются космическими;
    «AGM» — родная надпись, прочий текст — нечитаемые глифы.
15. **STEP1** → 128×32. Узкая серебристая кромка ступени (родня эталона
    STEP4) — только материал и фаска, без крупных деталей.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали у всех; по вертикали — у BASE, MC3,
   MC5, MC19, TEKWALL3, TEKWALL5 и PIPE2** (сплошные поверхности и трубы).
3. **Серии остаются сериями**: BRONZE1/3 — одна бронза; SHAWN1/02/3 — один
   серебристый металл с эталоном SHAWN2; MC3/5/19 — один мох с MC17;
   TEKWALL3/5 — одна электроника с TEKWALL1/2/4.
4. **Надписи**: читаемым остаётся только родной «AGM»; всё остальное —
   нечитаемые техно-глифы.
5. **Без запечённого света**: равномерное нейтральное освещение; светятся
   только экраны PLANET1, как в оригинале.
6. **Стиль**: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
