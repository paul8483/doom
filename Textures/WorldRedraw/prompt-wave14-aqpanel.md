## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй СЕМЬ текстур стен из классического DOOM (Freedoom, aquatex) в
повышенной детализации. Это серые клёпаные панели с вырезами под машинерию,
разметка и тёмный стеллаж затопленной техно-базы. Соседи по семейству уже
приняты — новые обязаны смотреться в одном ряду с ними.

**Эталоны aquatex** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQPANL06\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\AQSECT11\redraw.png`

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый элемент входа
(пластина, вырез, заклёпка-ряд, труба в проёме, полка) обязан остаться
ровно на своём месте и ровно своего размера в долях холста; число пластин,
вырезов и труб не менять. Перед сохранением сверь силуэты: наложение
результата на вход в полупрозрачности не должно показывать сдвигов.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 7 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **AQPANL01** → 512×512. Верхняя половина — серые клёпаные пластины с
   Y-образными вырезами, в вырезах видна оливково-зелёная подложка;
   нижняя половина — простые клёпаные пластины. Форма и позиции вырезов
   ровно по входу, зелёный остаётся зелёным.
2. **AQPANL02** → 512×512. Те же пластины, но в вырезах и по бокам видна
   машинерия — горизонтальные трубы и кабели (красные, зелёные, бурые
   сегменты); цвета сегментов — игровой сигнал, не глушить.
3. **AQPANL04** → 512×512. Родственная 02-й панель: серая клёпаная плита
   с центральным проёмом на машинерию из труб; нижняя треть — клёпаные
   пластины.
4. **AQPANL05** → 512×512. Простая стена из серых клёпаных пластин:
   вертикальные стыки, ряды заклёпок, царапины; без проёмов.
5. **AQPANL08** → 256×512. Две вертикальные секции частого рифления
   (тонкие рёбра) в клёпаных рамках сверху и снизу; число рёбер как во
   входе.
6. **AQPANL09** → 256×512. Диагональная чёрно-оранжевая предупредительная
   разметка во весь холст с клёпаной кромкой сверху; угол и толщина полос
   как во входе.
7. **AQSECT07** → 256×512. Тёмный стеллаж: сверху ржавая рама с белой
   световой планкой, в середине — сетка тёмных ячеек-отсеков, снизу —
   чёрно-жёлтая разметка. Ячейки и планка ровно по входу; светится только
   белая планка.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали у всех.**
3. **Серии остаются сериями**: AQPANL01/02/04/05 — одна система серых
   клёпаных панелей (один металл, одни заклёпки); AQPANL09 делит разметку
   с уже принятыми соседями.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и направленных теней (светится только планка AQSECT07).
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; больше деталей —
   слои ржавчины, потёки, фаски вырезов. НЕ фотореализм. Никаких надписей.
