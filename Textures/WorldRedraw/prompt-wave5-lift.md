# Волна 5, сет A: лифты и ступени — 7 текстур (GPT 5.6 SOL)

Повод — скриншот пользователя: борт лифта PLAT1 остался мягким на фоне
перерисованных стен. Ступени STEP* — те же лицевые кромки движущихся
секторов и лестниц, игрок смотрит на них в упор всю игру.
MIDGRATE исключена: masked-текстура с прозрачностью, редрав-пайплайн
держит только непрозрачные стены.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, размеры в промпте.
3. Сказать ассистенту — валидатор, тон, композиция, квант, установка.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй СЕМЬ текстур из классического DOOM (Freedoom) в повышенной
детализации. Это лифтовое хозяйство одной военной базы: лицевая панель
грузового лифта и шесть узких лицевых кромок ступеней/бортов. Единый
индустриальный стиль и освещение на весь набор.

**Эталон уровня детализации** — принятые перерисовки того же эпизода,
повторяй их манеру (плотность деталей, никакого фотореализма):
- `D:\Development\doom\Textures\WorldRedraw\STARTAN2\redraw.png`
- `D:\Development\doom\Textures\WorldRedraw\SUPPORT3\redraw.png`

Эти два файла ТОЛЬКО ЧИТАТЬ — не перерисовывать и не перезаписывать.
Полоса чёрно-жёлтых предупреждающих стрип на PLAT1 — та же деталь, что
решётка STARTAN2: рисуй их одной рукой.

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один**: каждый элемент входа (полоса,
колонна, арка, ряд заклёпок) остаётся ровно на своём месте и ровно своего
размера в долях холста; уменьшение или сдвиг — брак.

Вход каждой текстуры: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 7 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **PLAT1** → 512×512. Лицевая панель лифта: сверху полоса чёрно-жёлтых
   предупреждающих стрип во всю ширину; ниже — серая стена в вертикальных
   потёках с двумя арочными проёмами; арки и края обрамлены серыми колоннами
   с латунными капителями и основаниями; в глубине проёмов — тёмная
   машинерия из вертикальных труб, кабелей и блоков (остаётся тёмной и
   утопленной, рисунок машинерии повторяет вход).
2. **STEP2** → 128×32. Узкая медно-бурая кромка ступени с вертикальными
   насечками-рёбрами.
3. **STEP3** → 128×32. Узкая тёмно-оливковая кромка с тонкой светлой
   фаской по верху.
4. **STEP4** → 128×64. Серая стальная кромка со шлифовкой по диагонали
   (светлые разводы металла).
5. **STEP5** → 128×64. Тёмная кромка с двумя рядами круглых латунных
   заклёпок-кнопок.
6. **STEP6** → 128×64. Светло-бурая шершавая каменная кромка (грубый
   бетон/камень).
7. **STEPTOP** → 512×64. Широкая оливково-бурая лицевая планка ступени с
   мягким вертикальным градиентом.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали у всех семи** — лифт шире одной
   панели, ступени тянутся вдоль лестниц. По вертикали не требуется.
3. **Кромки остаются кромками**: у STEP* никакой крупной детализации,
   которая читалась бы «объектом» — только материал (металл, камень,
   заклёпки), фаска и износ; на экране они полосы в 8–16 юнитов высоты.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и направленных теней; машинерия PLAT1 тёмная сама по себе, а
   не затенена лампой.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; больше деталей —
   потёртые стрипы, фаски колонн, латунь капителей, зерно металла кромок.
   НЕ фотореализм. Никаких надписей.
