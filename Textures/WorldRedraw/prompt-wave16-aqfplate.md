## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ОДИННАДЦАТЬ текстур ПОЛОВ/ПОТОЛКОВ из классического DOOM
(Freedoom, aquatex) в повышенной детализации. Это серые стальные и
бетонные полы техно-базы: плиты, плитка, гофра, разметка. Ядро семейства
уже принято — новые обязаны смотреться в одном ряду с ним.

**Эталоны aquatex-флэтов** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQF032\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\AQF054\redraw.png`

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один.** Каждый элемент входа
(плита, шов, ребро, болт, полоса разметки) остаётся ровно на своём месте
и ровно своего размера в долях холста; число плиток, швов, рёбер и болтов
не менять. Перед сохранением сверь силуэты: наложение результата на вход
в полупрозрачности не должно показывать сдвигов.

**ВТОРОЕ — не копия:** каждый входной тексель — квадрат 4×4; ни один
такой квадрат не должен выжить как есть, внутри — новая деталь (поры
бетона, царапины стали, фаски плит).

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно 256×256. Ничего, кроме этих 11 `redraw.png`, не записывай.

Соответствие (имя → что на текстуре):

1. **AQF016** → два квадратных гофрированных блока (частые тонкие
   вертикальные рёбра) в серой стальной раме, болты по углам блоков.
2. **AQF017** → частые вертикальные серые планки, у каждой болт сверху и
   снизу; число планок ровно по входу.
3. **AQF046** → диагональная ёлочка (herringbone) из серых каменных
   кирпичей с тёмными швами; укладка ровно по входу.
4. **AQF050** → сетка квадратных серых бетонных плит с тонкими тёмными
   швами; число рядов и колонн ровно по входу.
5. **AQF051** → четыре КРУПНЫЕ серые стальные плиты 2×2 с крестовым швом
   и лёгкими царапинами. Это пол лифта — игрок смотрит на него в упор:
   фактура металла, потёртости от ног, фаски у швов.
6. **AQF052** → тёмно-серая плита со сплошной сеткой тонких диагональных
   царапин; направления царапин с входа.
7. **AQF055** → серый бетон с двумя горизонтальными каналами-ступенями со
   светлой кромкой; позиции каналов ровно по входу.
8. **AQF057** → мозаика квадратных серых блоков с фасками: верхние ряды
   крупнее, нижние мельче; раскладка ровно по входу.
9. **AQF067** → светло-серый гладкий бетон с мелкими порами и редкими
   тёмными точками; один слабый горизонтальный тональный шов посередине.
10. **AQF068** → квадратная серая бетонная площадка, по периметру рама
    жёлто-чёрной диагональной предупредительной разметки; жёлтый
    остаётся жёлтым, границы рамы ровно по входу.
11. **AQF075** → четыре крупные тёмно-серые подушкообразные плиты 2×2,
    каждая с диагональным X-рельефом (стёганый ромб); рельеф по входу.

Правила (те же, что у эталонов):
1. Композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех.**
3. **Серии остаются сериями**: AQF016/017 — одна клёпаная система;
   AQF050/051/052 — одно семейство стальных плит пола.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и направленных теней; ничего не светится.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; больше деталей —
   поры бетона, царапины стали, сколы фасок. НЕ фотореализм. Никаких
   надписей.
