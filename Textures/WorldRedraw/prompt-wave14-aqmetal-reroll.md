1. Перед приёмкой удалить старые `redraw-raw.png` этих 7 текстур.
2. Отправить текст промпта ниже одной сессией.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй СЕМЬ текстур стен из классического DOOM (Freedoom, aquatex) в
повышенной детализации. Это тёмный плетёный металл, вентиляционные решётки
и предупредительная разметка затопленной техно-базы.

**ГЛАВНОЕ ПРАВИЛО ЭТОГО ПРОГОНА — это ПЕРЕРИСОВКА, а не копия.** Вход —
пиксель-арт, растянутый 4×: он состоит из квадратов 4×4 одинакового цвета.
В результате НИ ОДИН квадрат 4×4 входа не должен выжить — каждая область
обязана получить настоящую мелкую деталь этого масштаба: волокна плетения,
зерно металла, царапины, окалину, градиенты на фасках. Итог должен нести
БОЛЬШЕ высокочастотной детали, чем вход, а не меньше. Сглаживать вход
запрещено.

**Второе правило — композиция один-в-один.** Каждый элемент входа (полоса,
прорезь, ячейка, шеврон) остаётся ровно на своём месте и ровно своего
размера в долях холста; число прорезей, ячеек и полос не менять.

**Эталоны честной перерисовки** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQMETL10\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\AQCOMP01\redraw.png`

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 7 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **AQMETL01** → 256×512. Однородный тёмный плетёный металл: прорисовать
   отдельные пряди плетения, зерно, ржавые точки.
2. **AQMETL06** → 512×512. Плетёный металл + V-образный шеврон
   чёрно-оранжевой разметки в металлической окантовке остриём вниз;
   потёртая краска полос, фаска окантовки.
3. **AQMETL09** → 256×512. Плетёный металл, четыре горизонтальные группы
   жалюзи-прорезей: глубина прорезей, тень внутри, фаски кромок.
4. **AQMETL28** → 256×512. Тёмная решётка горизонтальных щелей в шахматном
   перекрытии: объём перемычек, тень в щелях, латунный отлив.
5. **AQMETL30** → 256×512. Родня 28-й с более широкими щелями, серее;
   та же честная детализация.
6. **AQMETL32** → 256×512. Сетка квадратных ячеек с ржаво-оранжевым
   насечённым заполнением: рельеф насечки, объём переплёта.
7. **AQMETL33** → 256×512. Тёмная вафельная решётка мелких гнёзд
   (непрозрачная): глубина гнёзд, блики на рёбрах.

Правила: бесшовный тайлинг по горизонтали у всех, по вертикали — у
AQMETL01; серии остаются сериями (28/30, 32/33, 01/06/09); без запечённого
света; стиль — мрачный ретро-индастриал, гамма оригинала, НЕ фотореализм,
никаких надписей.
