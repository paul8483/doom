# Волна 12, сет 4: переключатели-ПАНЕЛИ, часть 2 — 6 пар / 12 файлов (GPT 5.6 SOL)

Пара SW1 (выключен) / SW2 (включён) рисуется как ОДНА композиция:
меняется только состояние индикаторов панели.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: по два `redraw.png` на пару.
3. Сказать ассистенту — валидатор, диф пары, тон, квант, установка.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ШЕСТЬ ПАР текстур переключателей из классического DOOM
(Freedoom) в повышенной детализации. Каждая пара — настенная
контрольная панель в двух состояниях. СНАЧАЛА СРАВНИ входы SW1 и SW2
каждой пары и найди различие (цвет индикатора, содержимое экрана) —
воспроизведи ровно его.

**ГЛАВНОЕ ПРАВИЛО ПАРЫ.** Внутри пары всё, кроме изменившегося
индикатора/экрана, ИДЕНТИЧНО попиксельно: рисуй SW1, сохрани, скопируй
и измени ТОЛЬКО различие для SW2.

**ВТОРОЕ ПРАВИЛО — композиция один-в-один с входом.** Не копия: каждый
входной тексель — квадрат 4×4, внутри новая деталь.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ):
- `D:\Development\doom\Textures\WorldRedraw\BROWN1\redraw.png` (ржавый металл BRN2)
- `D:\Development\doom\Textures\WorldRedraw\BROWNGRN\redraw.png` (зелёный металл BRNGN)
- `D:\Development\doom\Textures\WorldRedraw\GRAY1\redraw.png` (серый бетон GRAY/GRAY1)
- `D:\Development\doom\Textures\WorldRedraw\METAL2\redraw.png` (тёмный металл METAL)
- `D:\Development\doom\Textures\WorldRedraw\STONE2\redraw.png` (камень STON1)

Вход: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Выход: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`, ровно
в размере входа. Ничего, кроме этих 12 файлов, не записывай.

Пары (все 256×512):

1. **SW1BRN2 / SW2BRN2** → 256×512. Ржаво-оранжевая клёпаная стена,
   панель с зелёным экраном и кнопочным полем в нижней половине.
2. **SW1BRNGN / SW2BRNGN** → 256×512. Тёмно-зелёный клёпаный металл,
   та же панель с зелёным экраном.
3. **SW1GRAY / SW2GRAY** → 256×512. Светлые бетонные плиты, панель с
   зелёным экраном по центру нижней половины.
4. **SW1GRAY1 / SW2GRAY1** → 256×512. Те же бетонные плиты, панель
   меньше и смещена (сравни входы — раскладка с входа).
5. **SW1METAL / SW2METAL** → 256×512. Тёмные шестиугольные пластины
   брони, панель с зелёным экраном внизу.
6. **SW1STON1 / SW2STON1** → 256×512. Тёмная каменная кладка, панель с
   экраном и клавиатурой (сравни входы: индикаторы меняются).

Правила:
1. Правило пары — диф SW1↔SW2 вне зоны различия нулевой.
2. Бесшовный тайлинг по горизонтали И вертикали у обоих членов пары.
3. Без запечённого света; свечение экранов локальное.
4. Стиль: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей, кроме нечитаемых пиктограмм экранов как во входе.
