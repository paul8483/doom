## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` (RGBA) в папке каждой текстуры, размеры

   тон по непрозрачным текселям, квант с альфой, установка.

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ДЕВЯТЬ ПРОЗРАЧНЫХ (masked) текстур из классического DOOM
(Freedoom, aquatex) в повышенной детализации. Это решётки, сетки, цепи и
грунтовая кромка затопленной техно-базы — сквозь их дырки виден мир.
Принятые masked-соседи уже есть — новые обязаны смотреться в одном ряду.

**Эталоны** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `C:\Development\doom\Textures\WorldRedraw\AQMETL21\redraw.png`
- `C:\Development\doom\Textures\WorldRedraw\MIDBARS1\redraw.png`

**ГЛАВНОЕ ПРАВИЛО — прозрачность один-в-один.** Вход — RGBA с дырками;
каждый прозрачный тексель входа остаётся прозрачным, каждый непрозрачный —
непрозрачным (альфа бинарная 0/255, без растушёвки и полутонов). Прутья,
звенья и планки остаются ровно на своих местах и ровно своего размера в
долях холста; число прутьев/звеньев не менять. Перед сохранением сверь
силуэты: наложение результата на вход не должно показывать сдвигов, доля
прозрачных текселей должна совпасть с входом.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 9 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **AQMETL02** → 256×512. Горизонтальные металлические планки-жалюзи с
   просветами между ними (кирпичная перевязка планок); просветы
   прозрачные.
2. **AQMETL17** → 256×512. Свисающие сверху ржавые ЦЕПИ — несколько
   провисающих петель крупными звеньями; всё вне цепей прозрачно; форма
   петель ровно по входу.
3. **AQMETL24** → 256×512. Вертикальная колонна решётки вдоль ПРАВОГО
   края (сетка квадратных ячеек), остальное прозрачно.
4. **AQMETL25** → 256×512. Решётчатая рама: ряды ячеек сверху и колонна
   справа, центр прозрачный (угловой фрагмент сетки).
5. **AQMETL26** → 256×512. Диагональная плетёная латунная сетка-рабица
   во весь холст; ячейки прозрачные, переплетение ровно по входу.
6. **AQMETL27** → 256×512. Решётка квадратных ячеек в НИЖНЕЙ половине,
   верх прозрачный; граница решётки ровно по входу.
7. **AQMETL29** → 256×256. Ряды горизонтальных планок с просветами
   (короткая версия AQMETL02); просветы прозрачные.
8. **AQMETL31** → 256×256. Родственный 29-му ряд планок с чуть иным
   ритмом просветов; просветы прозрачные.
9. **AQDIRT03** → 512×512. Грунтовая кромка: почти весь холст прозрачен,
   вдоль нижнего края — неровная полоса земли/травы с торчащими пучками;
   силуэт кромки ровно по входу, зелень остаётся зеленью.

Правила (те же, что у эталонов):
1. Прозрачность и композиция один-в-один (см. главное правило).
2. **Бесшовный тайлинг по горизонтали у всех, кроме AQMETL24/25/27**
   (их решётка — краевой фрагмент, стык — граница контента как во входе);
   по вертикали — у AQMETL26.
3. **Серии остаются сериями**: AQMETL02/29/31 — одни планки;
   AQMETL24/25/27 — одна сетка; всё — тот же тёмный металл, что принятые
   AQMETL15/21.
4. **Без запечённого света**: равномерное нейтральное освещение, без
   виньеток и теней; ничего не светится.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала; больше деталей —
   ржавчина звеньев, фаски планок. НЕ фотореализм. Никаких надписей.
