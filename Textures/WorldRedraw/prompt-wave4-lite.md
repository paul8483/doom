# Волна 4, сет D (мини-волна): световые полосы LITE — 3 текстуры (GPT 5.6 SOL)

Отложены из основной волны 4 сознательно: LITE* входят в allowlist лампового
мерцания (`_LampFlickerParams` — шейдер гейтится по ЛЮМЕ текселей и бьёт
поверхность на UV-ячейки), поэтому у редрава есть два жёстких требования
сверх обычных: сегменты остаются ровно на своих местах (сетка ячеек) и
контраст «светится/не светится» не размывается. После установки — отдельный
QA мерцания на E1M5.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой текстуры, размеры в промпте.
3. Сказать ассистенту — валидатор, тон, композиция, установка, QA мерцания.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ТРИ текстуры стен из классического DOOM (Freedoom) в повышенной
детализации. Это встроенные в стену вертикальные световые полосы одной
военной базы: колонны из светящихся сегментов-плафонов, разделённых тёмными
перемычками. Один стиль светильника на все три.

**Эталон уровня детализации** — принятые перерисовки того же эпизода,
повторяй их манеру (плотность деталей, никакого фотореализма):
- `D:\Development\doom\Textures\WorldRedraw\COMP2\redraw.png`
- `D:\Development\doom\Textures\WorldRedraw\STARTAN2\redraw.png`

Эти два файла ТОЛЬКО ЧИТАТЬ — не перерисовывать и не перезаписывать.

**ГЛАВНОЕ ПРАВИЛО — композиция один-в-один**: количество сегментов, их
высоты и положения перемычек — ровно как во входе, без сдвигов; эти полосы
мерцают в игре посегментно, и сетка сегментов обязана совпасть с оригиналом.

**ВТОРОЕ ПРАВИЛО — контраст свечения**: плафоны остаются равномерно яркими
(это светящиеся поверхности), перемычки и рамки — тёмными. Не рисовать
полутоновых переходов, съедающих разницу «светится/не светится»; допустим
лишь лёгкий ореол по кромке плафона.

Вход каждой текстуры: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 3 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **LITE5** → 64×512. Узкая колонна белых светящихся плафонов со
   скруглёнными углами, между ними тонкие тёмные перемычки.
2. **LITEBLU4** → 64×512. Та же колонна, но плафоны светятся синим; в
   каждом лёгкий вертикальный градиент, как во входе.
3. **LITE3** → 128×512. Более широкая колонна белых плафонов той же серии
   с тёмной рамкой по бокам.

Правила (те же, что у эталонов):
1. Композиция один-в-один и контраст свечения (см. главные правила).
2. **Бесшовный тайлинг по горизонтали И вертикали у всех трёх** — полосы
   продолжаются вверх по стене.
3. **Одна серия**: форма плафонов, рамки и перемычки у всех трёх общие;
   LITEBLU4 отличается только цветом света.
4. **Без запечённого окружения**: никакого света, падающего на полосу
   извне, и никаких отражений комнаты; светятся только сами плафоны.
5. **Стиль**: ретро-техно, гамма оригинала; деталей немного и по делу —
   фаска рамки, лёгкая фактура стекла плафона, глубина перемычек.
   НЕ фотореализм. Никаких надписей.
