# Волна 15, сет 2: анимации «на месте» — ROCKRED1–3 + SLADRIP1–3 (GPT 5.6 SOL)

Эти серии НЕ прокрутка: кадры меняются локально (свечение лавы в камне,
капли шлама из ниши). Кадр 1 — якорь; кадры 2–3 рисуются «та же
композиция, движется только зона изменений», а вне дилатированной
нативной зоны изменений наш инструмент затем жёстко возьмёт тексели
якоря (обобщение enforce_switch_pair) — паразитный диф вне зоны не
страшен, но чем его меньше, тем чище фезер.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` в папке каждой из шести текстур.
3. Сказать ассистенту — валидатор, тон по якорю, пин вне зоны,
   панели. Имплементация — один раз в конце волны.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ШЕСТЬ текстур стен из классического DOOM (Freedoom) в
повышенной детализации. Это ДВЕ анимационные серии по три кадра;
внутри серии кадры отличаются ТОЛЬКО зоной анимации, всё остальное —
пиксель-в-пиксель одна картинка.

Вход каждой текстуры: `C:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `C:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 6 `redraw.png`, не записывай.

**Серия A — ROCKRED1/2/3 (512×512): раскалённый красный камень.**
Скальная кладка из крупных наклонных глыб, подсвеченных изнутри
лавовым жаром.
1. **ROCKRED1** → якорь: перерисуй один-в-один по входу — те же глыбы,
   те же трещины, та же карта свечения.
2. **ROCKRED2**, **ROCKRED3** → ТА ЖЕ кладка (глыбы и трещины не
   двигаются ни на пиксель), меняется только ЖАР: яркость свечения в
   трещинах и на гранях пульсирует ровно там, где меняются кадры входа
   (сверь по своим входам 2 и 3 против 1). Никаких новых трещин.

**Серия B — SLADRIP1/2/3 (256×512): стена со шламовой течью.**
Зеленоватые бронеплиты с заклёпками; внизу по центру тёмная ниша за
прутьями, из которой льётся и капает зелёный шлам.
1. **SLADRIP1** → якорь: перерисуй один-в-один — плиты, заклёпки,
   ниша, прутья, текущий шлам как во входе.
2. **SLADRIP2**, **SLADRIP3** → ТЕ ЖЕ плиты/ниша/прутья
   (пиксель-в-пиксель с твоим кадром 1), меняется только ШЛАМ: струи
   и капли сползают вниз, позиции капель — по входам 2 и 3.
   Зелёный остаётся зелёным.

Правила (общие для трека):
1. **Композиция один-в-один по входу**; внутри серии кадры вне зоны
   анимации идентичны, серия остаётся серией.
2. Анти-копия: больше высокочастотной детали, чем вход; ни один
   fat-pixel квадрат 4×4 не должен выжить.
3. **Бесшовный тайлинг по горизонтали** у всех шести.
4. **Стиль**: мрачный ретро-индастриал DOOM, гамма оригинала;
   НЕ фотореализм. Никаких надписей.

## Приёмка после генерации (наша часть, в GPT не отправлять)

```
python Tools/validate_tile_redraw.py ROCKRED1 ROCKRED2 ROCKRED3 SLADRIP1 SLADRIP2 SLADRIP3
python Tools/tone_match_redraw.py ROCKRED1 SLADRIP1   # тон — только якорям
python Tools/quantize_to_playpal.py <все шесть>
```

Затем пин вне зоны: кадры 2–3 вне дилатированной нативной зоны
изменений берут тексели якоря (фезер 4 px, инструмент волны по
образцу enforce_switch_pair), тон кадров 2–3 переносится с якоря
той же коррекцией, что применилась к нему.
