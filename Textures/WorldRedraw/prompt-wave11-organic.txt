# Волна 11, сет 2: masked стекло/лозы/проёмы — 4 текстуры (GPT 5.6 SOL)

Вторая половина прозрачных текстур: окно, свисающие лозы и кирпичные
проёмы. Дырки — настоящая прозрачность (альфа-канал).

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: `redraw.png` (RGBA!) в папке каждой текстуры.
3. Сказать ассистенту — валидатор `--masked`, хью-проверка зелени, тон,
   квант, установка.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ЧЕТЫРЕ ПРОЗРАЧНЫЕ текстуры из классического DOOM (Freedoom)
в повышенной детализации: оконная рама, свисающие с потолка лозы и два
кирпичных проёма. Игрок видит СКВОЗЬ прозрачные области. Соседние стены
уже перерисованы — не выбивайся из мрачного ретро-индастриала.

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ, не перезаписывать):
- `D:\Development\doom\Textures\WorldRedraw\BROVINE\redraw.png` (лозы — зелень)
- `D:\Development\doom\Textures\WorldRedraw\BROWN1\redraw.png` (бурый металл/стена)
- `D:\Development\doom\Textures\WorldRedraw\SHAWN2\redraw.png` (светлый металл рам)

**ГЛАВНОЕ ПРАВИЛО — АЛЬФА-СИЛУЭТ ОДИН-В-ОДИН.** Вход — RGBA PNG с
настоящей прозрачностью. Каждый прозрачный тексель входа остаётся
прозрачным, каждый непрозрачный — непрозрачным: рамы не толстеют, лозы
не отращивают новых ветвей, проёмы не зарастают. Результат — RGBA PNG;
фон НЕ запекать (дырки — альфа=0, не серый фон). Края жёсткие, кат-аут:
без полупрозрачной растушёвки и ореолов.

**ВТОРОЕ ПРАВИЛО — не копия.** Каждый исходный тексель — квадрат 4×4;
внутри непрозрачных областей ни один не должен выжить: волокна коры,
прожилки листьев, зерно кирпича, царапины рамы.

**ТРЕТЬЕ ПРАВИЛО — зелёное остаётся зелёным.** Лозы CEILVINE не буреют
(эталон BROVINE).

Вход каждой текстуры: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Результат сохранить в: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`
ровно в размере входа. Ничего, кроме этих 4 `redraw.png`, не записывай.

Соответствие (имя → размер выхода → что на текстуре):

1. **SMGLASS1** → 256×512. Двустворчатое окно: тонкая светлая
   металлическая рама по периметру и поперечина посередине, стёкла
   ВЫБИТЫ (прозрачны), в правых нижних углах створок висят обрывки
   цепочки. Рама и цепочки — ровно с входа.
2. **CEILVINE** → 512×512. Зелёные лозы, свисающие с верхней кромки
   вниз, с узлами и усиками; нижняя половина — редкие кончики. Маршрут
   каждой лозы — ровно с входа; зелень НЕ буреет.
3. **BRNSMAL1** → 256×256. Обломок бурой стены с ДВУМЯ узкими
   прямоугольными проёмами-бойницами. Кромки проёмов со сколами — по
   входу.
4. **BRNSMAL2** → 256×256. Родственный обломок той же стены, свой
   рисунок проёмов — серия с BRNSMAL1: один материал, один тон.

Правила (те же, что у эталонов):
1. Альфа-силуэт один-в-один (см. главное правило).
2. Композиция один-в-один.
3. **Бесшовный тайлинг по горизонтали И вертикали.**
4. **Без запечённого света**: равномерное нейтральное освещение.
5. **Стиль**: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей.
