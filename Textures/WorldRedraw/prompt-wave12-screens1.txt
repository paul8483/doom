# Волна 12, сет 3: переключатели-ПАНЕЛИ, часть 1 — 6 пар / 12 файлов (GPT 5.6 SOL)

Пара SW1 (выключен) / SW2 (включён) рисуется как ОДНА композиция:
меняется только состояние индикаторов панели.

## Как пользоваться (инструкция для нас, не для GPT)

1. Отправить текст промпта ниже одной сессией.
2. Ожидаемый выход: по два `redraw.png` на пару.
3. Сказать ассистенту — валидатор, диф пары, тон, квант, установка.

---

## Текст промпта (отсюда до следующего разделителя — в GPT)

Перерисуй ШЕСТЬ ПАР текстур переключателей из классического DOOM
(Freedoom) в повышенной детализации. Каждая пара — настенная
контрольная панель (экран, клавиатура, индикаторы) в двух состояниях.
СНАЧАЛА СРАВНИ входы SW1 и SW2 каждой пары и найди, ЧТО именно
меняется (цвет лампочки, содержимое экрана) — воспроизведи ровно это
различие, не выдумывая своего.

**ГЛАВНОЕ ПРАВИЛО ПАРЫ.** Внутри пары всё, кроме изменившегося
индикатора/экрана, обязано быть ИДЕНТИЧНЫМ попиксельно: рисуй SW1
полностью, сохрани, скопируй и измени ТОЛЬКО различие для SW2.

**ВТОРОЕ ПРАВИЛО — композиция один-в-один с входом.** Позиция панели,
раскладка экрана и клавиш, швы фона — ровно как во входе. Не копия:
каждый входной тексель — квадрат 4×4, внутри новая деталь (зерно
металла, свечение пикселей экрана, потёртые клавиши).

**Эталоны стиля** (ТОЛЬКО ЧИТАТЬ): фоны совпадают с уже принятыми
редравами соседей — совпадай по материалу:
- `D:\Development\doom\Textures\WorldRedraw\COMPUTE1\redraw.png` (техника COMP)
- `D:\Development\doom\Textures\WorldRedraw\BROWN1\redraw.png` (бурый металл BRCOM)
- `D:\Development\doom\Textures\WorldRedraw\SHAWN2\redraw.png` (светлый металл EXIT/COMM)
- `D:\Development\doom\Textures\WorldRedraw\STARTAN2\redraw.png` (панели STRTN)

Вход: `D:\Development\doom\Textures\WorldRedraw\upload\<ИМЯ>-native-x4.png`.
Выход: `D:\Development\doom\Textures\WorldRedraw\<ИМЯ>\redraw.png`, ровно
в размере входа. Ничего, кроме этих 12 файлов, не записывай.

Пары:

1. **SW1COMP / SW2COMP** → 256×512. Тёмная стойка кабелей и плат
   сверху, снизу стальная панель с зелёным экраном и клавиатурой.
2. **SW1BRCOM / SW2BRCOM** → 512×512. Бурая металлическая стена, малая
   панель слева-внизу: индикатор меняет цвет (сравни входы).
3. **SW1EXIT / SW2EXIT** → 128×288. Узкая светлая консоль ВЫХОДА:
   зелёный экран, решётка динамика, клавиатура; сверху зелёная лампа.
4. **SW1COMM / SW2COMM** → 256×288. Светлый металл, панель с двумя
   индикаторами и клавиатурой: индикаторы меняются (сравни входы).
5. **SW1MET2 / SW2MET2** → 256×512. Тёмное дерево-металл с клёпаными
   краями, панель вверху слева: индикатор красный → зелёный.
6. **SW1STRTN / SW2STRTN** → 256×512. Песочные каменные блоки, в
   нижней половине панель: индикаторы меняются (сравни входы).

Правила:
1. Правило пары — диф SW1↔SW2 вне зоны различия нулевой.
2. Бесшовный тайлинг по горизонтали И вертикали у обоих членов пары.
3. Без запечённого света; свечение экранов и ламп — локальное, без
   ореола на полстены.
4. Стиль: мрачный ретро-индастриал, гамма оригинала. НЕ фотореализм.
   Никаких надписей, кроме нечитаемых пиктограмм экранов как во входе.
