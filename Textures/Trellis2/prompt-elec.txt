# ELEC (вещь 48, высокая техно-колонна) — эскиз v2 (GPT 5.6 SOL)

Новый 3D-объект: техно-колонна `ELECA0` (26×128, один статичный кадр,
без ротаций). 25 штук на E1: E1M1 ×4, E1M2 ×2, E1M3 ×5, E1M7 ×4,
E1M9 ×10. Рецепт колонн COL1/COL2 (чистый объёмный рендер, крупные
раздельные формы — урок COLUA0), правило проекта: геометрия только
через TRELLIS.2.

## Как пользоваться (инструкция для нас, не для GPT)

1. Приложить к сессии ОДИН файл — полный путь в промпте.
2. Ожидаемый выход: ОДНА картинка, путь сохранения в промпте.
3. Дальше: TRELLIS.2 Space, seed 872506309, GLB в
   C:\Development\doom\Textures\Trellis2\GLB\ (имя ELECA0_<timestamp>.glb),
   сказать ассистенту — пит колонн (doomify preset A, `--palette-lump
   ELECA0`, `--tone-image` по нативному кропу, экранная калибровка),
   установка в Resources/ExperimentalPickups/ELECA0/, кейс 48 в
   ExperimentalPickupModel, маска эмиссии экрана (steady-путь лампы),
   тесты, панель, билд.

## Текст промпта (отсюда и до конца — в GPT)

Нарисуй ОДИН conditioning-эскиз для 3D-реконструкции: высокая
техно-колонна из DOOM (Freedoom) — напольная серверная/энергетическая
стойка от пола до потолка, вещь «tall techno pillar».

**Приложенный файл** (полный путь, читать оттуда):
`C:\Development\doom\Textures\Trellis2\NativeInputs\ELECA0-trellis.png` —
нативный спрайт, ЦЕЛЕВАЯ КОМПОЗИЦИЯ И ПАЛИТРА. Пропорции секций по
высоте (сверху вниз, доли полной высоты) сохранить один-в-один:
- 0–6%: расклёшенный тёмный колпак с ржавой кромкой;
- 6–41%: длинная секция РАДИАТОРНЫХ РЁБЕР (тонкие пластины рядами);
- 42–62%: гладкий стальной цилиндр, на нём три маленьких круглых
  порта-вентиляции вертикальной колонкой (в верхней части секции);
- 62–67%: узкая шея с ярким металлическим кольцом внизу;
- 67–74%: корпус с СИНИМ ЭКРАНОМ-CRT (прямоугольный дисплей в рамке);
- 75–84%: сужающийся воротник под экраном;
- 84–100%: постамент, расширяющийся к полу (в полу ширина максимальна),
  тёмная обшивка с тёплой ржавой кромкой у самого низа.

**Результат — одна картинка:** та же колонна как чистый объёмный
рендер БЕЗ пикселизации, вид строго с фронта, крупными раздельными
формами. Правила формы, критичные для реконструкции:
- Весь объект — ВЕРТИКАЛЬНОЕ ТЕЛО ВРАЩЕНИЯ (цилиндрические секции
  одной оси); объект очень вытянут — аспект силуэта примерно 1:5,
  колонна занимает всю высоту кадра.
- Радиаторные рёбра — ГЛАВНОЕ 3D-МЕСТО: каждый ряд — венец тонких
  пластин ВОКРУГ ВСЕЙ ОКРУЖНОСТИ цилиндра, с ракурсным сокращением:
  передние рёбра перекрывают тело, боковые видны в профиль как зубцы
  силуэта, задние чуть выглядывают из-за тела сверху. НЕ рисовать
  рёбра двумя плоскими гребёнками по бокам — реконструкция станет
  плоской.
- Колпак сверху и все кольца/фланцы — с читаемыми ЭЛЛИПСАМИ торцов
  (лёгкий взгляд чуть сверху), цилиндрическое радиальное затенение
  боков.
- Синий экран — УТОПЛЕННЫЙ в корпус прямоугольный дисплей в рамке с
  видимой глубиной фаски, только на фронтальной стороне; мягкое синее
  свечение изнутри, без бликов на соседних секциях.
- Постамент — гранёный/круглый пьедестал с панелями обшивки по всей
  окружности, расширение к полу читается эллипсами.
- Ничего не направлять в камеру; никакого выдуманного дизайна задней
  стороны — сзади те же промышленные формы по окружности.
- Палитра нативного спрайта: стальные серые, тёмный ганметал, ржавые
  акценты сверху и у пола, синий — только экран.

**Подача:** изолированный объект по центру на прозрачном/шахматном
фоне; без пола-текстуры, тени, окружения и текста; жёсткий читаемый
контур, естественная объёмная светотень.
