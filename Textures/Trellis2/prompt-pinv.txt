# PINV (вещь 2022, invulnerability) — эскиз v2 (GPT 5.6 SOL)

Новый 3D-объект: зелёная сфера неуязвимости `PINVA0` (25×25, анимация
A–D — игра бликов по стеклу; во Freedoom это ЗЕЛЁНЫЙ шар с гравировкой
пентаграммы, не синий). На E1 вещи НЕТ (стоит на E2M4/E3M5/E4M8/E4M9) —
гейт по панели + показ в редакторе через MapNameOverride на E2M4;
ассет впереди эпизодов. Решение по анимации: меш ОДИН, кадра A —
кадры отличаются только бликами, второй прогон TRELLIS дал бы дрожание
геометрии (урок SOUL/COL5/монстров); блики остаются 2D-делом.
Попутный долг бит-верности к установке: 2022/2024 добавить в
PickupAnimationTable (ванилла крутит A–D по 6 тиков, порт держит
кадр A).

## Как пользоваться (инструкция для нас, не для GPT)

1. Приложить к сессии ОДИН файл — полный путь в промпте.
2. Ожидаемый выход: ОДНА картинка, путь сохранения в промпте.
3. Дальше: TRELLIS.2 Space, seed 872506309, GLB в
   C:\Development\doom\Textures\Trellis2\GLB\ (имя PINVA0_<timestamp>.glb),
   сказать ассистенту — пит пикапов (doomify preset A, `--palette-lump
   PINVA0`, `--tone-image` по нативному кропу, экранная калибровка),
   установка в Resources/ExperimentalPickups/PINVA0/, кейс 2022 в
   ExperimentalPickupModel, маска эмиссии (steady-путь лампы: зелёное
   стекло светится ровно, гравировка пентаграммы тёмная), тесты,
   панель, билд.

## Текст промпта (отсюда и до конца — в GPT)

Нарисуй ОДИН conditioning-эскиз для 3D-реконструкции: сфера
неуязвимости из DOOM (Freedoom) — парящий зелёный стеклянный шар с
гравировкой пентаграммы, артефакт «invulnerability».

**Приложенный файл** (полный путь, читать оттуда):
`C:\Development\doom\Textures\Trellis2\NativeInputs\PINVA0-trellis.png` —
нативный спрайт, ЦЕЛЕВАЯ КОМПОЗИЦИЯ И ПАЛИТРА. Композицию гравировки
сохранить один-в-один:
- пятиконечная звезда занимает ~70% диаметра, вершиной вверх,
  центр звезды совпадает с центром сферы;
- в центре звезды — круглый выпуклый медальон-босс (~15% диаметра);
- лучи звезды — желобки, ПРОРЕЗАННЫЕ в стекле, с тёмными тенями в
  глубине и светлыми кромками;
- верхняя левая четверть: продолговатый холодный блик по стеклу.

**Результат — одна картинка:** та же сфера как чистый объёмный рендер
БЕЗ пикселизации, вид строго с фронта, крупными раздельными формами.
Правила формы, критичные для реконструкции:
- Весь объект — ШАР (аспект силуэта 1:1); контур — гладкая окружность,
  гравировка НЕ ломает силуэт.
- Пентаграмма — ГРАВИРОВКА на фронтальной полусфере: желобки утоплены
  в тело шара с читаемой глубиной (стенки желобков ловят свет), центр
  — выпуклый круглый босс; НЕ плоская наклейка, НЕ отверстия насквозь,
  НЕ отдельная звезда перед шаром.
- Задняя полусфера — гладкий зелёный шар БЕЗ выдуманного дизайна:
  никакой второй пентаграммы, узоров или швов сзади.
- Ничего не направлять в камеру; сферическое радиальное затенение к
  краям силуэта, материал — глубокое глянцевое стекло.
- Палитра нативного спрайта: насыщенные изумрудные и тёмные зелёные,
  почти чёрные тени в желобках, холодный светло-зелёный блик; никаких
  других оттенков.

**Подача:** изолированный объект по центру на прозрачном/шахматном
фоне; без пола, тени, окружения и текста; жёсткий читаемый контур,
естественная объёмная светотень.
