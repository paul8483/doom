# SOUL (вещь 2013, soulsphere / supercharge) — эскиз v2 (GPT 5.6 SOL)

Новый 3D-объект: жёлтая сфера-череп `SOULA0` (25×25, анимация A–D по
4 тика — «хохот», рот раскрывается всё шире). 11 штук на E1:
E1M1 ×1, E1M2 ×2, E1M3 ×2, E1M4 ×2, E1M6 ×1, E1M7 ×2, E1M9 ×1.
Решение по анимации: меш ОДИН, кадра A — повторные прогоны TRELLIS
дают дрожание геометрии (урок монстров/COL5), а морф рта четырьмя
независимыми генерациями на объекте в 25 px читался бы мерцанием;
хохот остаётся 2D-делом (прецедент BON1 — звёздный блик не поехал на
меш). Если на гейте меш покажется «мёртвым» — путь апгрейда:
stop-motion 4 меша по рецепту монстров (identity ref + один сид +
проекция хинта) плюс кадровый своп в ExperimentalPickupModel.

## Как пользоваться (инструкция для нас, не для GPT)

1. Приложить к сессии ОДИН файл — полный путь в промпте.
2. Ожидаемый выход: ОДНА картинка, путь сохранения в промпте.
3. Дальше: TRELLIS.2 Space, seed 872506309, GLB в
   C:\Development\doom\Textures\Trellis2\GLB\ (имя SOULA0_<timestamp>.glb),
   сказать ассистенту — пит пикапов (doomify preset A, `--palette-lump
   SOULA0`, `--tone-image` по нативному кропу, экранная калибровка),
   установка в Resources/ExperimentalPickups/SOULA0/, кейс 2013 в
   ExperimentalPickupModel, маска эмиссии (steady-путь лампы: золотая
   поверхность светится ровно, впадины глаз/рта/носа тёмные), тесты,
   панель, билд.

## Текст промпта (отсюда и до конца — в GPT)

Нарисуй ОДИН conditioning-эскиз для 3D-реконструкции: soulsphere из
DOOM (Freedoom) — парящая золотая сфера с рельефом черепа, артефакт
«supercharge».

**Приложенный файл** (полный путь, читать оттуда):
`C:\Development\doom\Textures\Trellis2\NativeInputs\SOULA0-trellis.png` —
нативный спрайт, ЦЕЛЕВАЯ КОМПОЗИЦИЯ И ПАЛИТРА. Композицию лица
сохранить один-в-один (доли высоты сферы, мерено по спрайту):
- 30–45%: две ГЛУБОКИЕ впадины глазниц, злобно скошенные к переносице;
- 45–55%: маленькая треугольная носовая впадина по центру;
- 55–85%: широко РАЗИНУТЫЙ рот-провал с рядом верхних зубов по кромке,
  нижняя «челюсть» — толстая золотая губа по низу сферы;
- верхняя левая четверть: яркий тёплый блик (глянцевая поверхность).

**Результат — одна картинка:** та же сфера как чистый объёмный рендер
БЕЗ пикселизации, вид строго с фронта, крупными раздельными формами.
Правила формы, критичные для реконструкции:
- Весь объект — ШАР, слегка вытянутый по вертикали (аспект силуэта
  ~1:1); контур силуэта — гладкий овал, лицо НЕ ломает контур.
- Лицо — БАРЕЛЬЕФ на фронтальной полусфере: глазницы, нос и рот —
  УГЛУБЛЕНИЯ в теле шара с читаемой глубиной (внутренние стенки и
  тени), а не плоские наклейки и не отверстия насквозь; зубы — мелкие
  выступы на верхней кромке рта.
- Задняя полусфера — гладкий золотой шар БЕЗ выдуманного дизайна:
  никакого второго лица, узоров или швов сзади.
- Ничего не направлять в камеру; лёгкий взгляд ровно с фронта,
  сферическое радиальное затенение к краям силуэта.
- Палитра нативного спрайта: насыщенное золото/жёлтый, тёмно-коричневые
  впадины, тёплый белый блик сверху слева, тонкая тёмная кромка по
  силуэту.

**Подача:** изолированный объект по центру на прозрачном/шахматном
фоне; без пола, тени, окружения и текста; жёсткий читаемый контур,
естественная объёмная светотень.
