# Doomify 3D — план

## Task 1 — Прототип фильтра (offline, без Unity)

`Tools/doomify3d.py`:

- палитра: полный PLAYPAL из `freedoom1.wad` или палитра native-спрайта
  (декод DOOM picture format) — режим `--palette playpal|native`;
- текстурный проход: albedo → downres до капа (default 256) → квантование в
  выбранную палитру (nearest RGB), альфа сохраняется;
- геометрический проход: quadric decimation (`fast-simplification`) до
  целевых треугольников (default 6k) + reprojection UV через
  closest-point/barycentric на исходном меше (emission-маски остаются
  валидными — UV-пространство то же);
- превью: маленький софтверный растеризатор (ortho, unlit textured,
  z-buffer, nearest sampling) → панели было/стало (2 ракурса) без Unity.

DoD: панели по ARM1A0 отправлены на интерактивный гейт.

## Task 2 — Интерактивный гейт стиля (ARM1A0)

Вердикт по панелям; при необходимости sweep параметров (кап текстуры
128/256, палитра native/PLAYPAL, 3k/6k/10k треугольников) отдельными
панелями. DoD: зафиксирован пресет параметров.

## Task 3 — Волна по Accepted мешам

Прогнать фильтр по всем мешам `Assets/Resources/ExperimentalPickups/`,
заменить albedo/OBJ (исходные GLB остаются в `Textures/Trellis2/GLB/` —
откат всегда возможен). Automation: EditMode/PlayMode suites, Windows build.
Интерактивный standalone гейт (это же закрывает decimation/finalization
долг: ~95k → 3–10k). DoD: вердикт SUCCESS + обновлённые заметки.

## Task 4 — Пилот монстра

POSSA1: детальный conditioning без стилевых ограничений (только верность
силуэту) → TRELLIS.2 → Doomify 3D → статические панели на стилевой гейт.
Без runtime-роутинга и анимации — только proof of style. DoD: вердикт,
запись в план TRELLIS.2.
