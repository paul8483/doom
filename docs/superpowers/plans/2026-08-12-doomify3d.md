# Doomify 3D — план

**Спека:** `docs/superpowers/specs/2026-08-12-doomify3d-design.md`

## Task 1 — Прототип фильтра (offline, без Unity)

`Tools/doomify3d.py`:

- палитра: полный PLAYPAL из `freedoom1.wad` или палитра native-спрайта
  (декод DOOM picture format) — режим `--palette playpal|native`;
- текстурный проход: albedo → downres до капа (default 256) → квантование в
  выбранную палитру (nearest RGB), альфа сохраняется;
- геометрический проход: quadric decimation (`fast-simplification`) до
  целевых треугольников (default 6k) + reprojection UV через
  closest-point/barycentric на исходном меше (emission-маски остаются
  валидными — UV-пространство то же);
- превью: маленький софтверный растеризатор (ortho, unlit textured,
  z-buffer, nearest sampling) → панели было/стало (2 ракурса) без Unity.

DoD: панели по ARM1A0 отправлены на интерактивный гейт.

## Task 2 — Интерактивный гейт стиля (ARM1A0)

Вердикт по панелям; при необходимости sweep параметров (кап текстуры
128/256, палитра native/PLAYPAL, 3k/6k/10k треугольников) отдельными
панелями. DoD: зафиксирован пресет параметров.

Ход (2026-08-12): v1 (fast_simplification + per-face rebake) — REJECT
(«антенна не читаема, качество плохое»); v2 (pymeshlab UV-децимация) —
«уже лучше». Sweep 6 вариантов + зумы: кандидаты пользователя A/E/F,
решение перенесено в игру. Вариант **F (20k / 256px / PLAYPAL)** заряжен в
`Resources/ExperimentalPickups/ARM1A0/` (obj+albedo подменены, mtl/emission
нетронуты; откат — `git checkout`). Находка: 10k рвёт тонкие детали
(наплечники) — нижняя граница бюджета ~20k.

In-game находка (2026-08-13): щель на куполе наплечника — децимация с
разблокированными границами растянула микротрещины воксельного меша
(33,320 граничных рёбер в 20k-меше). Фикс: `meshing_merge_close_vertices`
перед децимацией (84.6k → 44.9k вершин, почти половина — дубли вдоль
трещин); после сварки граничных рёбер **0**, меш водонепроницаемый.
Welded F перезаряжен в Resources, билд пересобран.

Вторая находка (2026-08-13): pymeshlab `save_current_mesh` копирует
исходную текстуру материала рядом с OBJ и затирает одноимённый
думифицированный albedo — первые in-game проверки шли с сырой 1024px
текстурой. Фикс: децимация до записи текстуры. Плюс импорт-сторона:
albedo нужен **Point + без сжатия** (bilinear+DXT съедали тексель).

**Task 2 DoD выполнен (2026-08-13): интерактивный in-game вердикт —
пресет A: 40k tris / 256px / native-палитра / Point / uncompressed +
обязательная сварка. «ну вот другое дело. оставляем вариант A».**
Известный нюанс: белёсый гем от аддитивного блинка (_PulseStrength 0.85
поверх квантованного красного) — тюнинг по желанию.

## Task 3 — Волна по Accepted мешам

Прогнать фильтр по всем мешам `Assets/Resources/ExperimentalPickups/`,
заменить albedo/OBJ (исходные GLB остаются в `Textures/Trellis2/GLB/` —
откат всегда возможен). Automation: EditMode/PlayMode suites, Windows build.
Интерактивный standalone гейт (это же закрывает decimation/finalization
долг: ~95k → 3–10k). DoD: вердикт SUCCESS + обновлённые заметки.

## Task 4 — Пилот монстра

POSSA1: детальный conditioning без стилевых ограничений (только верность
силуэту) → TRELLIS.2 → Doomify 3D → статические панели на стилевой гейт.
Без runtime-роутинга и анимации — только proof of style. DoD: вердикт,
запись в план TRELLIS.2.

## Task 3 — закрыто ✅ 2026-08-13 (интерактивный вердикт SUCCESS)

Все 24 меша на пресете A (сварка + 40k + 256px native + Point/uncompressed);
ARM1B0-меш роутится для брони 2018 (маска гема из albedo). Suites: EditMode
**624/624**, PlayMode **163/163**; Windows build Success, **183 МБ** (было
252 МБ, −69 МБ). Вердикт: «объекты стали однороднее, более похожи на единый
стиль»; гладкие предметы одумились, деревья без резких изменений.

Замечания → следующий этап (регенерация + повторная думификация):

- **BAR1A0** — бочка и так была в дум-стиле, после фильтра «расплылся
  рисунок» (запечённая пиксель-графика мельче нашего текселя, BOX-усреднение
  её смазало). Дешёвая альтернатива регенерации: per-asset texcap 512 или
  без палитризации.
- **COLUA0** — верхушка фонаря превратилась «в набор пикселей».
- **BON1A0** — не изменилась, но исходное качество низкое; кандидат на
  новую генерацию.
