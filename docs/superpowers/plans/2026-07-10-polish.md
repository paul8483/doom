Для каждого прогона использовать уникальные XML/log. Открытый Unity Editor
блокирует batchmode; в этом случае закрыть Editor или явно отметить прогон
`BLOCKED`, но не объявлять PASS по старому XML.

```powershell

& "C:\Program Files\Unity\Hub\Editor\6000.4.8f1\Editor\Unity.exe" `
```

## Источник истины: campaign route

Маршрут не вычислять простым `map + 1`; normal и secret transitions держать в
одной immutable таблице. Перед реализацией сверить реальные exits
`freedoom1.wad` compatibility audit'ом.

| Current | Normal | Secret | Примечание |
|---|---|---|---|
| E1M1 | E1M2 | E1M9 | secret применяется только при special 51/124 |
| E1M2 | E1M3 | E1M9 | |
| E1M3 | E1M4 | E1M9 | canonical E1 secret entry |
| E1M4 | E1M5 | E1M9 | controlled fallback допустим при нестандартном WAD |
| E1M5 | E1M6 | E1M9 | |
| E1M6 | E1M7 | E1M9 | |
| E1M7 | E1M8 | E1M9 | |
| E1M8 | EpisodeComplete | E1M9 | normal завершает эпизод |
| E1M9 | E1M4 | E1M4 | возврат в основной маршрут |

Для точной DOOM-совместимости secret route должен учитывать карту, из которой
был выполнен вход. Если audit/референс показывает иной return target,
исправить таблицу, spec и tests одновременно, а не добавлять special case в
Unity controller.

## Источник истины: save schema v1

| Блок | Stable ID | Обязательное состояние |
|---|---|---|
| Header | slot/envelope | magic, version, WAD identity, map, payload length, checksum |
| Session | map + tic | route context, transition, next SpawnId, stats |
| Player | singleton | transform/view, health/armor, ammo, backpack, weapons, keys, powers, RNG |
| Sector | WAD sector index | floor/ceiling/light, active mover phase/target/speed/wait |
| Line | WAD linedef index | fired state, switch state, active executor state |
| Map thing | THINGS index | present, transform, HP, FSM/frame, target |
| Runtime entity | SpawnId | drops and projectiles, owner/target references |

Никогда не сериализовать `GetInstanceID`, GameObject name, Unity object
reference, Mesh/Material/Texture/AudioClip или enumeration order.

## Stop conditions

- **Compatibility audit нашёл новый progression blocker:** остановить
  соответствующую map acceptance, добавить explicit design/test/task; не
  переклассифицировать blocker в harmless.
- **Freedoom UI lump naming отличается от retail DOOM:** каталог должен
  обнаруживать реальные lumps и документировать fallback; не добавлять
  authored replacement asset.
- **Full snapshot не может выразить authoritative runtime state:** сначала
  добавить stable capture/restore API владельцу state, затем продолжить codec.
- **Save format allocation может зависеть от untrusted counts:** добавить
  bounds до allocation; malformed file никогда не должен приводить к OOM.
- **Scene reload оставляет duplicate persistent host/service:** исправить
  lifecycle до добавления следующей persistent system.
- **Optimization ломает sector movers, UV, saves или E1 карту:** откатить
  конкретную optimization и оставить baseline evidence; correctness важнее
  target improvement.
- **Unity batchmode заблокирован открытым Editor:** отметить test run BLOCKED;
  не использовать старый XML как доказательство.
