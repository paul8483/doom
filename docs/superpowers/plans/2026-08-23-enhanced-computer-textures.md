# Enhanced перерисовка компьютерных текстур — план

**Спека:** `docs/superpowers/specs/2026-08-23-enhanced-computer-textures-design.md`
**Ветка:** `3d-toggle`
**Статус:** ✅ закрыт 2026-08-24 («проверил, всё хорошо») — 20 текстур
(COMP* ×19 + AQCOMP01), пайплайн v10, EditMode 671/671, PlayMode 191/191,
build ~358 MB. Хроника резкости: шарпен L0 (v9) → шарпен всех мипов (v10) →
bias −0.5/−0.25 отвергнут за шиммер → bias 0 принят.

Пилот — COMP2 + COMPTALL (кадр пользователя). Правила этапа, которые пилот
обязан решить: палитра (PLAYPAL-квант против полноцвета), качество швов,
чтение texel-AA/нормалей/POM поверх редрава.

## Task 1 — инструменты и нативы

- `Tools/export_wall_texture.py <LUMP>` — композитор TEXTURE1/PNAMES/PLAYPAL →
  `Textures/WorldRedraw/<LUMP>/native.png` (1×) + `native-x4.png` (integer
  nearest 4×, вход для GPT: «перерисуй ровно эту картинку в этом размере»).
- `Tools/validate_tile_redraw.py <LUMP>` — техгейт до показа: размер строго
  4× натива по WAD, полная непрозрачность, **шов**: средняя разница обёрнутой
  пары краевых столбцов (и строк для флэтов) против средней разницы соседних
  столбцов внутри картинки; порог калибруется на нативе (натив тайлится —
  его коэффициент ≈ 1).
- `Tools/quantize_to_playpal.py <LUMP>` — из полноцветного редрава делает
  PLAYPAL-вариант. **Одна генерация — два варианта палитры**: квантование
  деterministично на нашей стороне, варианты отличаются только палитрой, и
  решение пользователя не смешивается с лотереей второй генерации.

## Task 2 — промпт и редравы (генерация — пользователь, GPT 5.6 SOL)

- Один промпт на пилотную пару с явной привязкой «файл → результат»
  ([[hint-prompt-name-native-files]]); текст хранится в
  `Textures/WorldRedraw/prompt-pilot.md`.
- Требования в промпте: та же композиция один-в-один (панели/экраны/решётки на
  своих местах), бесшовный тайлинг по горизонтали, нечитаемые техно-глифы на
  экранах (не английский), без запечённого света/виньеток, выход ровно
  1024×512.
- Приёмка: `validate_tile_redraw.py` на оба файла; провал шва — краевое
  лечение или регенерация. Затем `quantize_to_playpal.py` → 4 файла:
  `redraw.png` (полноцвет) + `redraw-pal.png` на каждую текстуру.

## Task 3 — рантайм

- `Assets/Resources/EnhancedWorld/<LUMP>.png` (readable, uncompressed, без
  авто-мипов — уровни строит наш генератор) + allowlist в коде.
- Шов в мировом альбедо-пайплайне: для лампа из allowlist вход `WorldAlbedo` —
  редрав как уровень 0 вместо dedither→Super-xBR; ключ кэша тот же
  `(name, Enhanced4X)`, wrap сохраняется, нормали/POM едут от albedo-мипов
  автоматически (`ForWorldNormal`), фолбэк per-item на Super-xBR при
  отсутствии/браке файла.
- Мипы: для полноцветного варианта — режим без PLAYPAL-снапа уровней
  (иначе перелив на мип-переходах); квант-вариант идёт старым путём.
- `EnhancedPipelineVersion` v6 → **v7**; паки дропнет `CleanupStalePacks`.

## Task 4 — тесты

- EditMode `ComputerRedrawAssetTests`: по allowlist — файл в Resources,
  размер = 4× натива из WAD, непрозрачность, шов (пин валидатора; сначала
  пин на нативе как калибровка); сторож — файл без лампа в allowlist не
  лежит сиротой.
- PlayMode: материал COMP2 в Enhanced несёт редрав (1024×512 у ключа
  `(COMP2, Enhanced4X)`); ламп без файла строится Super-xBR; Classic — натив.

## Task 5 — панель, standalone, гейт

- Панель было/стало ([[visual-verdict-workflow]]): натив | текущий Super-xBR |
  редрав-квант | редрав-полноцвет, кропы вблизи + сцена кадра.
- Слот сохранения на точке скрина пользователя (COMP2 + COMPTALL в кадре).
- Windows build; интерактивный гейт в standalone. Вердикт фиксирует палитру
  для всего этапа. Провал — этап закрывается без рантайм-долга (allowlist
  пуст, мир остаётся на Super-xBR).

## Закрытие (2026-08-24) — что случилось после установки волны 1

- **Гейт средней дистанции чуть не завалил этап.** Пользователь дважды показал
  «всё равно нечётко»: сперва это оказалась чужая текстура (AQCOMP01 →
  добавлена в волну), затем — настоящая проблема: панели 1:1 обманывают,
  в игре на обычной дистанции виден мип 1–2, а box-мипы редрава размывали
  весь выигрыш. Лечение в два шага, по одному на билд: (v9) SharpenFilter 0.5
  на уровень 0 — «в упор» стало «прям разница ощутимая»; (v10) шарпен всех
  мип-уровней ≥8 px — принята средняя дистанция.
- **Mip bias провален**: −0.5 и −0.25 дали шиммер при движении;
  `RedrawMipBias = 0`, шов в `TextureCache` оставлен.
- **Texel-AA crossover**: в зоне ~0.5–1.2 текселя/px fat-pixel уступает
  билинейке — это и делало нешарпленный редрав мягким там, где игрок стоит
  чаще всего. Сужение зоны отложено как запасной крутил.
- **AQPANL01–09 исключены по осмотру** (клёпаный металл, не компьютеры);
  сет-промпты волны 1: 17 COMP одной сессией с эталоном стиля пилота +
  AQCOMP01 отдельной (другой фон).
- **Побочно убит хронический флейк** `HudPlayTests` (пин случайного кадра
  взгляда STFST00 → семейство STFST0[0-2]): загрузка ресурсов волны сдвинула
  тайминг сцены, и флейк стал детерминированным — три красных прогона подряд
  вскрыли настоящую причину, кочевавшую через три волны.
- Панельный конвейер волны: `make_worldredraw_panel.py` (автокроп по самой
  яркой зоне), Super-xBR-стороны панелей — из расширенного
  `UpscalePreviewMenu`.
