managed Nuked OPL3 (LGPL-2.1; точный upstream commit фиксируется при

Минимальные кейсы:

```csharp
[Test]
public void Decode_format3_reads_rate_and_unsigned_pcm()
{
    byte[] lump = Dmx(format: 3, rate: 11025, samples: new byte[] { 0, 128, 255 });
    DecodedSound s = DmxSound.Decode(lump);
    Assert.That(s.SampleRate, Is.EqualTo(11025));
    Assert.That(s.Samples, Is.EqualTo(new byte[] { 0, 128, 255 }));
}

[TestCase(2)]
[TestCase(4)]
public void Decode_rejects_non_digital_format(int format) { /* FormatException */ }

[Test]
public void Decode_rejects_short_or_overdeclared_payload() { /* bounds */ }
```

Builder пишет little-endian header: `UInt16 format`, `UInt16 sampleRate`,
`UInt32 sampleCount`, затем payload.

- [ ] **Step 3: Реализовать pure decoder.**

```csharp
public sealed class DecodedSound
{
    public int SampleRate { get; }
    public byte[] Samples { get; }
}

public static class DmxSound
{
    public static DecodedSound Decode(byte[] lump);
}
```

Требования:
- `null`, `< 8 bytes`, format != 3, rate == 0, count > remaining bytes →
  `InvalidDataException`;
- count читается как `UInt32 LE`, checked conversion в `int`;
- стандартные 16 lead + 16 trail padding удаляются только при длине,
  позволяющей оставить полезный payload, и если padding состоит из
  unsigned silence (`128`; допустимо `0` для совместимых WAD-вариантов).
  Если тест real-WAD показывает другой валидный паттерн — зафиксировать его
  тестом до изменения.

- [ ] **Step 4: `SoundCatalog`.**

`TryRead(WadFile wad, string lumpName, out DecodedSound)` нормализует имя в
upper case, требует prefix `DS`, использует `FindLump`/`ReadLump`, не
сохраняет `WadFile`.

- [ ] **Step 5: Freedoom integration.**

Открыть `freedoom1.wad`, проверить минимум `DSPISTOL`, `DSSHOTGN`,

- [ ] **Step 2: `SoundSystem`.**

API:

```csharp
public void Init(SoundCache cache, float worldScale, int poolSize = 16);
public AudioSource PlayLocal(string lumpName);
public AudioSource PlayAt(string lumpName, Vector3 position);
public void PlayLoop(string lumpName, object ownerKey, Vector3 position);
public void StopLoop(object ownerKey, string stopLump = null);
public bool WasPlayed(string lumpName); // internal/public test probe
```

Пул — дочерние GO сервиса. One-shot source возвращается при
`!isPlaying`; loop отдельно индексируется по `ownerKey`, повторный start не
создаёт второй source. Настройки:
- local: `spatialBlend=0`;
- world: `spatialBlend=1`, linear rolloff,
  min=`160*worldScale`, max=`1200*worldScale`, doppler=0;
- music не входит в этот пул.

`WasPlayed`/`LastPlayedLump` — наблюдаемое состояние для PlayMode без
зависимости от audio device; не использовать в геймплейной логике.

## Известные риски и стоп-условия

- **LGPL/Unity compatibility:** до vendor обязательно зафиксировать лицензию
  и возможность распространять исходники core. Если политика проекта не
  допускает LGPL — Task 8 блокирован до выбора MIT/BSD managed OPL core;
  внешний SoundFont или Windows MIDI не являются допустимым обходом.
- **Audio thread:** любая аллокация/Unity API/logging в PCM callback —
  дефект; ловить pure benchmark-тестом и profiler'ом.
- **WAD lifetime:** ни SFX, ни музыка не читают disposed `WadFile`.
- **MUS timing:** 140 Hz event clock не равен игровым 35 tics/s.
- **Double fireball sound:** owner launch cue ровно один — brain или
  projectile, не оба.
- **Sector origin:** sector root at `(0,0,0)` нельзя использовать как
  позицию звука.
- **Headless audio:** PlayMode asserts state/configuration, финальная
  слышимость подтверждается только интерактивно.

## Зафиксированные упрощения

- 16 pooled SFX sources вместо точного DMX 8-channel arbitration.
- Unity linear rolloff 160..1200 DOOM units, без sector occlusion.
- Один OPL/GENMIDI music backend.
- Нет random pitch, doppler, reverb, HRTF tuning.
- Нет footstep SFX.
- Звуки ещё не реализованных gameplay specials остаются до их этапов.
