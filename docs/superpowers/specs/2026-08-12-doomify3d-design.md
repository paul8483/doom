# Doomify 3D — единый стилевой пост-процесс для Enhanced 3D ассетов (design)

**Дата:** 2026-08-12
**Ветка:** `3d-toggle`
**Статус:** принято направление, Stage 1 (валидация на принятом меше) в работе
**Связано:** доктрина `2026-08-07-enhanced-ai-derived-assets-design.md`,
план `2026-08-06-trellis2-pickups.md`

## Проблема

Conditioning-картинка для TRELLIS.2 сейчас обслуживает две противоречащие цели:

1. **Геометрия** — TRELLIS должен уверенно прочитать объём: нужны выраженные
   depth cues, светотень, детализация.
2. **Стиль** — результат должен читаться как предмет пиксельного мира DOOM:
   чанки, узкая палитра, без глянца.

Для простых тел (деревья v2, ROCKA0, BAR1A0) цели совпадают: объём читается
с почти-оригинальной картинки, и меши выходят «в стиле». Для брони пришлось
существенно перерисовывать вход; для монстров v2-хинты TRELLIS вообще не
воспринимает — нужны детальные перерисовки, которые дают глянцевый,
выбивающийся из мира результат («Heroes 3 3D-remake» failure mode). Поиск
компромиссной картинки стоит ~10 генераций на объект, и для сложных объектов
точки компромисса может не существовать.

## Решение: развязать геометрию и стиль

**Conditioning-картинка отвечает только за геометрию.** Рисуем её в том
качестве, в котором TRELLIS сохраняет детали объекта. Единственное жёсткое
правило — идентичность: силуэт и пропорции WAD-спрайта, без придуманных
частей. «Гладкость»/детальность входа больше не критерий гейта.

**Doom-стиль обеспечивает Doomify 3D** — единый детерминированный
пост-процесс на нашей стороне, один и тот же для каждого меша:

1. **Альбедо** → квантование в WAD-палитру + кап разрешения (128–256 px) +
   Point-фильтр. Убивает запечённый глянец и фотореализм, даёт чанки-текселы.
   Режимы палитры: полный PLAYPAL или палитра native-спрайта лампа
   (прецедент — принятый remap деревьев в trunk/leaf палитру).
2. **Геометрия** → decimation до 3–10k треугольников. Low-poly сам по себе
   читается как ретро; это же закрывает давно запланированную
   finalization-волну (~95k сырых треугольников на ассет).
3. **Шейдер** — без изменений: `Doom/ExperimentalPickupUnlit` + SectorFog.
4. Опционально: воксельный remesh как пресет для отдельных предметов
   (прецедент — принятый стилизованный BON1A0).

## Почему это сработает (прецеденты)

- **BON1A0**: строгий гейт формы REJECT, но в игре принят именно как
  стилизованная воксельная колба — стилизация спасла ассет.
- **Деревья TRE2/SMIT**: приняты только после remap альбедо в WAD-палитру;
  «generated PBR texture не считается автоматически финальным» уже записано
  в плане TRELLIS.2.
- **Глянец не из шейдера**: всё сидит на unlit — блики запечены в альбедо,
  их снимает палитризация + downres.
- **doomify_shapehint.py**: тот же алгоритм (квантование + чанки) уже принят
  для 2D shape-hints.

## Выигрыши

- Сложные объекты (броня, монстры) получают вход, который TRELLIS понимает,
  без штрафа за стиль; ожидаемо меньше генераций на объект.
- Единообразие: стиль всем ассетам придаёт один фильтр, а не удача
  конкретной перерисовки — дерево, броня и монстр гарантированно из одного
  мира.
- **Единая точка управления графикой**: параметры фильтра (размер палитры,
  кап текстуры, целевые треугольники) меняются один раз — пересобирается вся
  коллекция; возможны пресеты стиля.

## Риски и ограничения

- Палитризация не убирает **придуманную геометрию** (лишние ремни, накладки
  останутся в силуэте) → правило верности силуэту WAD-спрайта остаётся
  центральным критерием conditioning.
- Decimation с сохранением UV: reprojection через closest-point может дать
  смазы на UV-швах — проверяется на гейте Stage 1.
- Freedoom PLAYPAL широкая — квантование в полный PLAYPAL слабое; основной
  вклад чанки-стиля даёт downres, сильный вариант — палитра native-спрайта.
- Монстрам всё равно нужны риггинг/анимация: статичный меш — только proof of
  style; монстры не диктуют пайплайн, а проверяются после стабилизации
  фильтра.

## Гейты

1. **Stage 1**: прототип фильтра на уже принятом «гладком» меше (ARM1A0) без
   новых генераций; панели было/стало → интерактивный вердикт стиля.
2. Фиксация параметров пресета → прогон волны по всем Accepted мешам
   (= finalization wave), automation + standalone гейт.
3. Пилот монстра (POSSA1): детальный conditioning → TRELLIS → Doomify 3D →
   статический стилевой гейт.
