# Enhanced 3D monster pilot (POSS) — design

**Дата:** 2026-08-13
**Ветка:** `3d-toggle`
**Статус:** черновик → пилот в работе

## Что

Первый полностью функциональный 3D-монстр в Enhanced: зомби (POSS, doomednum
3004) ходит, атакует, получает боль и умирает, будучи представленным
doomified TRELLIS.2-мешами вместо спрайтового билборда. Classic и геймплей
не затрагиваются вообще.

## Почему

Доктрина AI-derived assets (2026-08-07) называет монстров отдельным
экспериментальным треком со строжайшим гейтом аутентичности. Пикапы,
декорации и деревья уже прошли: пайплайн conditioning → TRELLIS.2 →
Doomify 3D (пресет A) выдаёт единый стиль («объекты стали однороднее»).
Монстр — следующий уровень сложности: он анимирован и поворачивается.

## Ключевое решение: стоп-моушен по кадрам

Принято обсуждением 2026-08-13. Вместо риггинга — отдельный doomified-меш
на каждый живой кадр анимации, переключаемый в 35-тиковом ритме брейна,
как в Voxel Doom:

- сохраняется дискретный DOOM-ритм анимации (аутентичность);
- риггинг/скелет/скиннинг не нужны — пайплайн Doomify 3D переиспользуется
  без изменений;
- поворот меша по `DoomAngleDegrees` заменяет выбор из 8 ротаций спрайта —
  монстр впервые становится по-настоящему круговым.

### Покрытие кадров POSS

| Кадры | Frames | Представление |
|-------|--------|---------------|
| Стойка/походка A–D | 0–3 | 3D-меши (4 шт.) |
| Атака E–F | 4–5 | 3D-меши (2 шт.) |
| Боль G | 6 | 3D-меш (1 шт.) |
| Смерть H–K, труп L | 7–11 | **revert to billboard** (паттерн бочки BEXP) |
| XDeath M–U | 12–20 | revert to billboard |

Итого 7 генераций TRELLIS.2. Смерть на билборде — сознательный компромисс
пилота: паттерн проверен на бочке, кадры смерти без ротаций и живут секунды.

## Риски

1. **Дрейф идентичности между кадрами** — 7 независимых генераций могут
   дать «разных зомби». Митигация: Stage 2 — пилот консистентности на
   кадре B до массовой генерации; палитризация Doomify унифицирует
   текстуры; при дрейфе — per-frame shape-hints с общим référence.
2. **Скачки геометрии при свапе мешей** — нормализация масштаба/якоря
   per-frame по высоте нативного патча кадра (как SpriteHeightPx).
3. **Аутентичность анимации** — переключение 7 мешей может читаться иначе,
   чем спрайтовая анимация; решает только интерактивный гейт.
4. **Производительность** — 7×40k tris на инстанс в памяти; на E1M1
   десятки POSS. Меши шарятся между инстансами (Resources), активен один.

## Гейты

- Gate S1 (стиль): статические панели doomified POSSA1 vs native спрайт.
- Gate S2 (консистентность): панель A-меш vs B-меш.
- Gate S3 (все кадры): панель 7 кадров.
- Gate Final (интерактивный): standalone E1M1, монстр в бою — походка,
  атака, боль, смерть, поворот, Classic/3D Off фолбэки. Вердикт
  пользователя = единственный критерий SUCCESS.

## Ограничения пилота

- Только POSS; SPOS/TROO/SARG/BOSS — после вердикта по образцу.
- Спектр-полупрозрачность не затрагивается (SARG-вопрос).
- Кадры смерти в 3D — возможный follow-up, не в пилоте.
